# カード センタリング測定ツール

ポケモンカードなどのトレーディングカードの**センタリング**（ふちの左右・上下の比率）を測定する Web ツールです。
斜めから撮影した写真でも、**射影変換（ホモグラフィ）で遠近を補正**してから測定します。

- 画像はブラウザ内だけで処理されます（サーバーへのアップロードなし）
- スマホ・PC 両対応（ドラッグ中は拡大鏡を表示）
- ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）

## 使い方

1. カードの写真を選ぶ（撮影・ファイル選択・ドラッグ&ドロップ・貼り付け）
2. 4つのハンドルをカードの角に合わせる
   - カードの角は丸いので、点線（辺の延長線）がカードの4辺に重なるように合わせます
3. 「遠近補正して測定」を押すと、正面から見た画像に補正され、縁の線が自動検出されます
4. ずれている線はドラッグ（または微調整ボタン・矢印キー）で合わせます
5. 左右・上下の比率、ふちの幅(mm)、PSA 基準でのセンタリングの目安が表示されます
6. 「結果画像を保存」で、線と数値入りの画像を保存できます

## 仕組み

| 処理 | 内容 |
| --- | --- |
| 遠近補正 | 指定した4隅 → カードの実寸比（63×88mm など）の長方形へのホモグラフィを8元連立方程式で求め、逆写像 + バイリニア補間で補正画像を生成 |
| 縁の検出 | 補正画像で、カード中央部の行（列）ごとの色勾配を積算し、直線状のエッジのピークを検出（放物線補間でサブピクセル精度） |
| 比率 | 左 = 内側左 − 外側左、右 = 外側右 − 内側右 として `左 / (左 + 右)` を計算（上下も同様） |

## 公開方法（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、ブランチ（例: `main`）とフォルダ `/ (root)` を選んで保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ローカルで試す場合は、リポジトリのフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開きます。

## 注意

- 表示されるグレードは、公開されている PSA のセンタリング基準に当てはめた目安です。実際の鑑定結果を保証するものではありません。
- レンズの歪み（広角での近接撮影）やカードの反りは補正できません。少し離れて撮影するのがおすすめです。
- 非公式のファンメイドツールです。株式会社ポケモン・任天堂・各鑑定会社とは関係ありません。
