# アイコン

ホーム画面のアイコン「右肩上がりの記録」（候補のうち E3 改）。

## 込めたこと
| 絵 | 意味 |
|---|---|
| 解体新書の人体図のような立ち姿の人 | 人の体を、科学的に調べる |
| 方眼紙と、右肩上がりの折れ線（青 → 金色） | 記録を続けると、体調がよくなっていく |
| だんだん細くなるばらつきの帯 | 記録がたまるほど、わかったことが確かになる（分析の「差の範囲」） |
| 月と太陽、折れ線の先から太陽への点線 | 眠りから、すっきりした朝へ |
| 夜の青の地 | 寒色をもとにする。睡眠のアプリなので夜の色 |
| 人の肌、朱色の心臓、人の後ろの淡い光 | 寒色の中でも、人のぬくもりを残す |

胸から左へのびる解剖図の引き出し線と丸は、時計の針のように見えるので入れない。

## 3枚の絵
| ファイル | 使われるとき |
|---|---|
| `AppIcon.svg` | ふつうのホーム画面 |
| `AppIcon-Dark.svg` | iPhone をダーク表示にしたとき（地を少し暗くしたもの） |
| `AppIcon-Tinted.svg` | アイコンを色付き表示にしたとき（白黒。明るいところほど、選んだ色が濃くのる） |

## 作り直し方
絵は `app_icon.py` で描いている（色や形を変えるときは、このファイルを直す）。

```sh
python3 ios/Design/app_icon.py           # SVG を書く
node ios/Design/render_app_icon.mjs      # 1024px の PNG にして App/Assets.xcassets/AppIcon.appiconset に入れる
```
PNG にするには、Playwright（Chromium）と Python の Pillow が要る。App Store の決まりに合わせて、PNG には透明な部分を入れない。
