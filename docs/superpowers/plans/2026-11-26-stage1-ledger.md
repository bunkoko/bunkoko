- Ruling R5: label year rule = `(?<!\d)(?:19|20)\d{2}\s*年` (covers 年度) or `(明治|大正|昭和|平成|令和)\s*[0-9０-９元]+\s*年`; bare 4-digit numbers are allowed — spec says "年・元号・数を入れない" about years; counts like 2000人 are legitimate labels — cost if wrong: a label like 「2013」 alone slips through (reviewer/owner see it).

- Ruling R8: CLI tests set `KOTEN_CONTACT` to a value with "@" that is not example.com (e.g. "test@koten.invalid") — `_make_fetcher` refuses otherwise — cost if wrong: none.
- Ruling R9: `page_items(drafts, *, excerpt: Callable[[dict], dict | None] | None = None)`; the CLI passes a provider that fetches the file through net.py into data/estat-cache and reads it with files.read_grid; tests pass a fake — keeps page_items pure — cost if wrong: file cards show no excerpt when no provider is given.
