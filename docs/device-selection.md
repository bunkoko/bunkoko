# デバイス選定（ドラフト v0.4）

[要件定義書](./requirements.md) の「4.2 環境データ」を取るためのスマートホーム機器の比較と推奨構成。

- 作成日: 2026-11-12
- 方針: **取れるデータの種類が最も多い構成**にする（v0.2 で決定）
- 住環境: **寮のワンルーム**（廊下なし。ドアを開けるとすぐ部屋。風呂は共同）
- 価格と販売状況は変わるため、購入前に公式ストアなどで確認すること。
- 「[要確認]」は公式資料で確かめきれていない項目。
- 各機器で取れる項目は、SwitchBot API v1.1 の公式資料（2026-11-12 時点）で確認した。

| 版 | 日付 | 変更内容 |
|---|---|---|
| v0.1 | 2026-11-12 | 初版（最小構成を推奨） |
| v0.2 | 2026-11-12 | 「取れるデータが最も多い構成」に変更。SwitchBot ハブの違いを追加。ハブ3を推奨に |
| v0.3 | 2026-11-12 | 将来分も含めて購入リストを確定（8章）。浴室の防水温湿度計・寝室のドアの開閉センサーを追加 |
| v0.4 | 2026-11-12 | 寮のワンルームに合わせて見直し。浴室・屋外・他の部屋のセンサーとハブミニをやめる。カーテン3は U型1台＋ソーラーパネル。プラグミニを2個に（加湿空気清浄機用を追加）。寮の Wi-Fi の注意、引掛シーリング・温湿度計の違いの説明を追加 |

## 1. 選定の基準

| 基準 | 理由 |
|---|---|
| **取れるデータの種類が多い** | 最優先。睡眠に関係しそうな要因をできるだけ記録しておき、後から何が効いているかを分析する |
| **クラウド API で外から取れる** | サーバーが定期的に値を取りに行く構成のため。将来サービス化したときも、ユーザーの家にサーバーを置かずに済む |
| **API の資料がそろっていて、利用回数に余裕がある** | 台数を増やしても上限に達しないこと |
| **日本で買いやすく、使っている人が多い** | サービス化したとき、ユーザーがすでに持っている可能性が高い |
| **将来の家電操作に広げられる** | 付録Bの「自動制御」に進むとき、同じメーカーでエアコンや照明を操作できると楽 |

| | **A. SwitchBot** | **B. Nature Remo** | **C. Home Assistant + 各社センサー** | **D. Netatmo** |
|---|---|---|---|---|
| 室温・湿度 | ○ | ○（Remo 3） | ○ | ○ |
| CO2 | **○（CO2センサー）** | ×（別のメーカーが必要） | ○（Aranet4 など。精度が高い） | ○ [要確認] |
| 部屋の明るさ | △（段階値。最大20段階） | ○（Remo 3。単位は [要確認]） | ○（ルクスで取れるセンサーあり） | × [要確認] |
| 在床（止まっている人の検知） | **○（人感センサー Pro）** | × | ○（ミリ波センサーなど） | × |
| 照明の明るさ・色温度 | **○（シーリングライトなど）** | × | 照明次第 | × |
| 窓の開閉・カーテン・消費電力 | **○** | ×（消費電力は別製品 [要確認]） | ○ | × |
| 騒音 | × | × | センサー次第 | ○ [要確認] |
| 外から取る方法 | クラウド API（v1.1）＋ Webhook | クラウド API | 自宅のサーバーに API でアクセス（外から使うには別途の設定が必要） | クラウド API |
| API 利用回数の上限 | **1日 10,000 回** | 5分あたり 30 回とする情報が多い [要確認] | 自分のサーバーなので上限なし | [要確認] |
| 手軽さ | ◎ | ◎ | △（常時動くサーバーの用意と設定が必要） | ○ |
| サービス化との相性 | ◎（利用者が多い） | ◎（利用者が多い） | △（使える人が限られる） | △（日本での販売状況は [要確認]） |

**結論: SwitchBot にする。** クラウド API で取れるデータの種類が最も多い。特に「在床」「照明の明るさ・色温度」「窓の開閉」は、他のメーカーでは取りにくい。

Home Assistant（C）は機器を自由に組み合わせられるので、理論上は最も多くのデータを取れる。ただし自宅で常に動くサーバーが必要になり、サービス化したときに一般のユーザーには使ってもらいにくい。SwitchBot で取れない騒音などが必要になったら、追加で検討する（[5章](#5-switchbot-では取れないデータと補い方)）。

## 3. SwitchBot ハブの違い

ハブは、Bluetooth でつながるセンサーの値をクラウドへ送る中継役。**CO2センサーや人感センサー Pro の値を API で取るには、ハブが必要。** 「ハブ1」という製品名はなく、初代は「ハブ」「ハブプラス」「ハブミニ」の世代にあたる。

| | ハブ / ハブプラス / ハブミニ（初代の世代） | **ハブ2** | **ハブ3** |
|---|---|---|---|
| 発売 | 2017年〜（ハブ・ハブプラスは販売終了） | 2023年ごろ | 2025年5月 |
| 赤外線リモコン（エアコン・テレビの操作） | ○ | ○ | ○ |
| センサー値をクラウドへ中継 | ○ | ○ | ○ |
| Matter 対応 | ハブミニの Matter 対応版のみ | ○ | ○ |
| **温度・湿度センサー** | × | ○ | ○ |
| **照度センサー**（API の値） | × | ○（**1〜20** の20段階） | ○（**1〜10** の10段階） |
| **人感センサー** | × | × | **○** |
| 画面 | なし | 小さな表示（温湿度） | 2.4インチのカラー画面（温湿度・天気・CO2 なども表示） |
| 操作 | なし | タッチボタン | ボタン＋ダイヤル |
| API で取れる項目の数 | 0（中継のみ） | 3（温度・湿度・照度） | **4（温度・湿度・照度・人の動き）** |
| 価格の目安 | ハブミニが最も安い | 8,980〜9,980円（記事により差あり） | 16,980円（2026年8月の価格改定後） |

**推奨はハブ3。** 取れるデータの種類が最も多い（人の動きが取れる）。照度はハブ2より粗い（10段階）が、人感センサー Pro で20段階の照度が取れるので補える。CO2センサーの値を画面に出せるので、寝る前に部屋の状態を見るのにも便利。

## 4. 推奨構成（寮のワンルーム向け）

すべて1つの部屋に置く。ワンルームなので、ハブ3 の Bluetooth はすべての機器に届く見込み（中継用のハブミニは不要）。

### 4.1 基本（必須）
| 機器 | 台数 | 置き場所 | API で取れるデータ | 睡眠の分析での使い道 |
|---|---|---|---|---|
| **ハブ3** | 1 | 部屋 | 温度・湿度・照度（10段階）・人の動き | 中継役。室温・湿度の2つ目の測定点。夜中に起きた時刻 |
| **CO2センサー（温湿度計）** | 1 | 枕元付近 | 温度・湿度・**CO2（0〜9,999ppm）** | 換気不足と睡眠の質の関係 |
| **人感センサー Pro** | 1 | ベッドだけが見える位置 | **在床（止まっている人も検知）**・照度（20段階） | 布団に入った・出た時刻。睡眠中の部屋の暗さ |

※ 人感センサー Pro はミリ波レーダーで呼吸などの小さな動きもとらえるため、寝ていて動かない人も検知できる。普通の「人感センサー」は動いている人しか検知できず、明るさも「明るい / 暗い」の2段階なので、こちらを選ぶ。

### 4.2 追加推奨
| 機器 | 台数 | 置き場所 | API で取れるデータ | 睡眠の分析での使い道 |
|---|---|---|---|---|
| **開閉センサー** | 2 | 窓（よく開ける窓）と部屋のドア | 開閉・照度（明るい / 暗い） | 換気した時刻と CO2 の下がり方。窓を開けて寝た夜の比較。ドアの開閉から**外出・帰宅の時刻**もわかる |
| **シーリングライト**（通常版） | 1 | 天井 | **照明のオン・オフ、明るさ（1〜100）、色温度（2,700〜6,500K）** | 就寝前の照明の明るさ・色と寝つきの関係。消灯した時刻 |

※ シーリングライトは今の照明と付け替えになる。天井に「引掛シーリング」があること（[9.1](#91-引掛シーリングとは)）と、寮の規則で付け替えてよいことが前提。
※ シーリングライトプロとの違いは赤外線リモコンの有無だけで、**API で取れるデータは同じ**。赤外線リモコンはハブ3 にあるので、通常版で足りる。

### 4.3 任意（さらにデータを増やす）
| 機器 | 台数 | 置き場所 | API で取れるデータ | 睡眠の分析での使い道 |
|---|---|---|---|---|
| **カーテン3**（U型） | 1 | カーテン（両開きの片側） | カーテンの開き具合 | 朝に日光を入れた時刻、夜の遮光。将来は朝に自動で開ける |
| **ソーラーパネル（カーテン3専用）** | 1 | カーテン3 に取り付け | —（データなし） | カーテン3 の充電が不要になる |
| **プラグミニ** | 2 | ① 加湿空気清浄機 ② テレビ・パソコン・スマホの充電器など | 消費電力・使用時間 | ① **加湿・空気清浄をしていた時間**（消費電力の変化から推定 [要検証]） ② 就寝前の画面の使用。スマホの充電器につなぐと「スマホを手放した時刻」の目安になる可能性がある [要検証] |

※ カーテンは両開きだが、片側だけ開けば朝の光は入るので1台にする。

### 4.4 置かないもの（住環境による）
| 場所 | 理由 | 代わりの方法 |
|---|---|---|
| 浴室 | 共同浴場のため置けない | 入浴した時刻はアプリでワンタップ入力する |
| 屋外 | 寮のため設置しにくい | 外の気温・湿度・気圧は天気 API で取る |
| 他の部屋 | ワンルームのため不要 | — |

### 4.5 API の利用回数の試算
購入リストの9台（ソーラーパネルを除く）を5分ごとに取得した場合: 9台 × 1日288回 ＝ **1日 約2,600回**。上限の 10,000回に対して十分余裕がある。人感センサー Pro・開閉センサー・ハブ3 の人の動きは、変化したときに届く Webhook でも受け取り、正確な時刻を記録する。

## 5. SwitchBot では取れないデータと補い方

| データ | 取れない理由 | 補い方 |
|---|---|---|
| エアコンの設定温度・運転状態 | 赤外線リモコンは送るだけで、エアコンの状態を読み取れない | 室温の変化から推定する。必要ならエアコンのメーカーのアプリ・API を後で検討 |
| 騒音 | 騒音を測る SwitchBot 製品がない | Apple Watch の環境音データ（[要確認]）。必要になったら他のメーカーを検討 |
| 正確な明るさ（ルクス） | 照度は段階値のみ | 人感センサー Pro の20段階＋シーリングライトの設定値＋ Apple Watch の「日光を浴びた時間」で補う |
| PM2.5・VOC（空気の汚れ） | SwitchBot の空気清浄機は、API では運転状態しか返さない | 対象外。今の加湿空気清浄機が Wi-Fi 対応なら、メーカーのアプリで見られる可能性がある（[9.3](#93-今ある加湿空気清浄機の扱い)） |
| 外の気温・湿度・気圧 | 屋外にセンサーを置かない | 天気 API で取る |
| 入浴した時刻 | 浴室にセンサーを置けない | アプリで手入力 |

## 6. 寮・ワンルームで使うときの注意

### 6.1 寮の Wi-Fi（買う前に必ず確認）
SwitchBot のハブは、**パスワードだけでつながる 2.4GHz の Wi-Fi**（WPA2-PSK など）にしかつながらない。SwitchBot 公式サポートによると、次の Wi-Fi は**使えない**。

| 使えない Wi-Fi | 見分け方 |
|---|---|
| ブラウザでログインする Wi-Fi（キャプティブポータル） | つなぐとログイン画面が出て、学籍番号や部屋番号などを入れる |
| ID とパスワードで認証する Wi-Fi（WPA2-エンタープライズ / 802.1X） | パスワードのほかに「ユーザー名」も入れてつなぐ |
| 5GHz だけの Wi-Fi | 2.4GHz の電波が出ていない |

寮の Wi-Fi が使えない場合の対処:
| 対処 | 内容 |
|---|---|
| 自分用の Wi-Fi ルーターを置く | 部屋に有線 LAN の差し込み口があり、寮が許可していれば、ルーターをつないで 2.4GHz・パスワード方式の Wi-Fi を作る |
| ホームルーター・モバイルルーターを使う | SIM で通信するルーターを置く（月額の通信料がかかる） |
| スマホのテザリング | 24時間つなぎっぱなしにできないので、常用には向かない |

確かめ方: 寮の Wi-Fi の案内を見るか、管理者に確認する。スマホで寮の Wi-Fi につなぐときに「ユーザー名」やブラウザのログイン画面が出たら、そのままでは使えない。

### 6.2 寮の規則
- **照明の付け替え**が認められているか確認する。付け替える場合、**元の照明は保管**して退去時に戻す。
- 開閉センサーや人感センサー Pro は両面テープで取り付ける。**はがせる両面テープ**を使い、壁や窓枠を傷めないようにする。
- カーテン3 はカーテンレールに引っ掛けるだけなので、部屋に傷は付かない。

### 6.3 ワンルームならではのデータの扱い
- 寝る場所と過ごす場所が同じなので、照度・人の動きには日中の生活も含まれる。分析では「睡眠中」「就寝前2時間」などの時間帯で区切って使う。
- 在床を正しく判定するため、人感センサー Pro は**ベッドだけが入る向き**に置く。机やドアの前が入ると、起きているのに「在床」と判定されやすい（検知する距離をアプリで調整できるかは [要確認]）。

## 7. 置き方とチェックリスト

### 7.1 置き方のポイント
- **CO2センサー**: 頭の高さに近い位置で、顔から 1〜2m ほど離す（吐く息が直接当たると高く出る）。窓・ドア・エアコンの風が直接当たる場所や、直射日光の当たる場所は避ける。加湿空気清浄機の風が直接当たる場所も避ける。
- **人感センサー Pro**: ベッドだけが見える位置・向きに置く（6.3）。
- **ハブ3**: 部屋の中で、将来操作するエアコン・加湿空気清浄機が見通せる位置に置く（赤外線が届くように）。
- **開閉センサー**: いちばんよく開ける窓と、部屋のドアに付ける。
- 置き場所を決めたら動かさない（場所が変わると値が比べられなくなる）。動かした場合はアプリに記録する。

### 7.2 チェックリスト
買う前:
- [ ] **寮の Wi-Fi に SwitchBot のハブがつながるか**を確認する（6.1）。つながらない場合は、自分用のルーターを用意できるか確認する
- [ ] 天井に引掛シーリングがあるか確認する（9.1）
- [ ] 部屋の広さ（畳数）を確認する（シーリングライトの 6畳 / 8畳 を選ぶ）
- [ ] 寮の規則で、照明の付け替えとテープでの取り付けが認められているか確認する（6.2）
- [ ] 加湿空気清浄機のメーカー・型番を確認する（9.3）
- [ ] Apple Watch の機種を確認する（手首皮膚温は Series 8 以降 / Ultra）

買った後:
- [ ] SwitchBot アプリでハブとセンサーを登録し、センサーの「クラウドサービス」を有効にする（API の `enableCloudService`）
- [ ] SwitchBot アプリの「開発者向けオプション」で API のトークンとシークレットを発行する（手順は公式資料で確認）
- [ ] API でセンサーの値が取れることを確認する（`GET /v1.1/devices/{deviceId}/status`）
- [ ] Apple Watch を寝るときに着ける習慣を作る（充電は朝の身支度中などに）

## 9. 補足

### 9.1 引掛シーリングとは
天井に付いている、**照明をつなぐための差し込み口**（配線器具）。照明本体を差し込んでひねるだけで付け外しでき、工事は要らない。日本の住宅の天井照明の多くはこれで付いている。

| 項目 | 内容 |
|---|---|
| 見た目 | 天井に付いた白い樹脂の器具（四角または丸）。弓のような形の差し込み穴が2つある |
| 種類 | 角型・丸型・埋込ローゼットなど。種類ごとに付けられる照明の重さの上限があるので、シーリングライトの商品ページの対応表で確認する |
| 確かめ方 | 今の照明のカバーを外し、天井との付け根を見る。照明が上記の器具に差し込まれていれば引掛シーリング |
| ない場合 | 照明が天井に直接ネジで留められ、電線が直接つながっている（「直付け」）。新しく付けるには電気工事士の資格が必要な工事になるため、寮では現実的でない |

**引掛シーリングがない、または付け替えが認められない場合の代わり**: SwitchBot のスマート電球（API で明るさ・色温度が取れる）を、電気スタンドなど E26 口金の照明に付ける方法がある。ただし、その照明の分しかデータが取れない [要確認]。

### 9.2 温湿度計の無印・プラス・Pro の違い
**API で取れるデータはどれも同じ（温度・湿度）。** 違うのは画面と精度。

| | 温湿度計（無印） | 温湿度計プラス | 温湿度計Pro |
|---|---|---|---|
| 画面の大きさ | 2.1インチ | 3.0インチ | 3.66インチ |
| 画面に出るもの | 温度・湿度 | 温度・湿度・快適度 | 温度・湿度・日時・天気予報、防水温湿度計の値も同時に表示 |
| バックライト | なし | なし | あり |
| 精度 | 標準 | 記事によって差あり | 最も高い（温度 ±0.2℃・湿度 ±2% とする記事が多い） |
| 価格の目安 | 約2,000円 | 約2,500〜3,000円 | 約3,500円 |

この構成では、CO2センサー（温湿度計）とハブ3 で室温・湿度が取れるため、どれも買わなくてよい。

### 9.3 今ある加湿空気清浄機の扱い
今の構成で取れるデータ・できること:
| 方法 | 内容 |
|---|---|
| プラグミニで消費電力を測る | 動いていた時間、強さの変化（消費電力から推定 [要検証]）。今回の購入リストに入っている |
| ハブ3 の赤外線リモコンで操作する | 本体に赤外線リモコンが付いていれば、将来の自動制御でオン・オフや加湿の切り替えができる [要確認] |
| メーカーのアプリ（Wi-Fi 対応の機種のみ） | 機種によっては PM2.5・ホコリ・湿度などが見られる。ただし、メーカーが外部向けの API を公開していないことが多く、このツールに取り込めるかは [要確認] |

メーカー・型番がわかれば、どこまでできるかを確認する。
