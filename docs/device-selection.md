# デバイス選定（ドラフト v0.1）

[要件定義書](./requirements.md) の「4.2 環境データ」を取るためのスマートホーム機器の比較と推奨構成。

- 作成日: 2026-11-12
- 価格と販売状況は変わるため、購入前に公式ストアなどで確認すること。
- 「[要確認]」は公式ドキュメントで確かめきれていない項目。

---

## 1. 選定の基準

| 基準 | 理由 |
|---|---|
| **睡眠に関係する項目が取れる** | 室温・湿度・**CO2**・照度。特に CO2 は寝室を閉め切ると上がりやすく、温湿度計だけでは取れない |
| **クラウド API で外から取れる** | サーバーが5分ごとに値を取りに行く構成のため。将来サービス化したときも、ユーザーの家にサーバーを置かずに済む |
| **API の資料がそろっていて、利用回数に余裕がある** | 5分ごとの取得を続けても上限に達しないこと |
| **日本で買いやすく、使っている人が多い** | サービス化したとき、ユーザーがすでに持っている可能性が高い |
| **将来の家電操作に広げられる** | 付録Bの「自動制御」に進むとき、同じメーカーでエアコンや照明を操作できると楽 |

補足（SwitchBot API v1.1 の公式資料で確認した内容）:
- CO2センサー（API 上の名前は `MeterPro(CO2)`）: `temperature`（℃）、`humidity`（%）、`CO2`（0〜9999ppm）が取れ、Webhook にも対応。
- Hub 2: `temperature`、`humidity`、`lightLevel`（1〜20）。
- Hub 3: `temperature`、`humidity`、`lightLevel`（1〜10）、`moveDetected`（人感）。
- 人感センサー: 明るさは `bright` / `dim` の2段階だけ。
- いずれも過去の値を取る API はないため、サーバーが定期的に取得して保存する必要がある。

## 3. 推奨: A. SwitchBot で始める

理由:
1. **CO2・温湿度・照度・人感が1つのメーカーでそろう**。
2. API の資料が公開されていて、1日 10,000 回の上限は5分ごとの取得（1台あたり 1日 288 回）に対して十分な余裕がある。
3. 日本での利用者が多く、サービス化したときにも対応する価値が高い。
4. 将来、エアコンや照明の操作に広げられる。

弱点と対策:
| 弱点 | 対策 |
|---|---|
| 照度が段階値で、正確なルクスではない | 寝室で必要なのは「就寝前に明るすぎないか」「睡眠中に暗いか」の判定なので、段階値でも足りる見込み。日中に浴びた光は Apple Watch の「日光を浴びた時間」で補う。足りなければ拡張構成で照度センサーを足す |
| 騒音が取れない | 当面は対象外。必要になったら拡張で検討（Apple Watch の環境音データも参考にする） |
| API キーを利用者に手で入力してもらう必要がある（OAuth ではない） | サービス化のときに、連携画面で入力手順をわかりやすく案内する |

## 4. 推奨構成

### 4.1 最小構成（まずこれで始める）
| 機器 | 台数 | 置き場所 | 取れるデータ |
|---|---|---|---|
| **SwitchBot CO2センサー（温湿度計）** | 1 | 寝室・枕元付近 | 室温・湿度・CO2 |
| **SwitchBot ハブ（Hub 2 または Hub 3）** | 1 | 寝室 | 照度（段階値）・室温・湿度（Hub 3 は人感も） |

Hub 2 と Hub 3 の選び方:
- **Hub 2**: 照度が 20段階で細かい。費用を抑えたい場合に。販売状況は要確認。
- **Hub 3**: 照度は 10段階だが、**人感センサーがある**ため「布団に入った時刻」の推定に使える。

※ CO2センサーの値をクラウドに送るには、ハブが必要（センサーはハブ経由でクラウドにつながる）。

### 4.2 拡張構成（Phase 2 以降に必要なら）
| 機器 | 目的 |
|---|---|
| 温湿度計（リビング・書斎など） | 寝室との温度差、日中の環境を見る |
| 屋外用の温湿度計 | 外気との差を見る（天気 API で代わりにできる） |
| ルクスで測れる照度センサー（Home Assistant と Zigbee センサーなど） | 段階値では足りないとわかった場合 |
| 騒音を測れる機器 | 騒音の影響を見たくなった場合 |

## 5. 置き方のポイント
- **CO2センサー**: 頭の高さに近い位置で、顔から 1〜2m ほど離す（吐く息が直接当たると高く出る）。窓・ドア・エアコンの風が直接当たる場所や、直射日光の当たる場所は避ける。
- **ハブ（照度）**: センサー部分を物でふさがない。電気スタンドの真下など、部屋全体の明るさと違う場所は避ける。将来エアコンを操作するなら、エアコンが見通せる位置に置く。
- 置き場所を決めたら動かさない（場所が変わると値が比べられなくなる）。動かした場合はアプリに記録する。

## 6. 購入前・購入後のチェックリスト
- [ ] 自宅の Wi-Fi が 2.4GHz に対応している（SwitchBot のハブは 2.4GHz のみ [要確認]）
- [ ] SwitchBot アプリでハブとセンサーを登録し、センサーの「クラウドサービス」を有効にする（API の `enableCloudService`）
- [ ] SwitchBot アプリの「開発者向けオプション」で API のトークンとシークレットを発行する（手順は公式資料で確認）
- [ ] API でセンサーの値が取れることを確認する（`GET /v1.1/devices/{deviceId}/status`）
- [ ] Apple Watch を寝るときに着ける習慣を作る（充電は朝の身支度中などに）
- [ ] Apple Watch の機種を確認する（手首皮膚温は Series 8 以降 / Ultra）
