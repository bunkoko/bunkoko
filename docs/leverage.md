# レバレッジの上限を上げたら — 事前登録

書いた日: 2026-10-23（計算する前）。実行: `./cfd table … --lev 1,2,4 --long --max-dd <許容の下げ>`（Mac）

## 1. なぜ確かめるか

2026-10-23 の `./cfd table --long`（構成 `config/baselines/turtle55_d1_ext.json`、資金 1,000 万円）で、1 回の損失を
1.5% → 4% に上げても、先物の 20 年分の年率は 4.1% → 3.9% と増えず、最大の下落だけが 19.0% → 38.5% に大きくなった。
最大のレバレッジは 1.5% のときからすでに 2.0 倍前後で、**合計のレバレッジの上限（2 倍）** に当たっているのが理由と考えられる。

問い: **レバレッジの上限も一緒に上げれば、1 回の損失に比例して年率も上がるか。そのとき下げはどこまで大きくなるか。**

## 2. 計算すること

`./cfd table`（`scripts/risk_table.py`）に `--lev`（レバレッジの上限の倍率）を足して、次の組み合わせを全部計算する:

- 1 回の損失: 1.5%・2%・3%・4%（同時に持てる合計 4 銘柄分と、グループ 2 銘柄分の上限も同じ比率で上げる。今の表と同じ）
- レバレッジの上限: 今の 1 倍（1 銘柄 1 倍・合計 2 倍）、2 倍（2 倍・4 倍）、4 倍（4 倍・8 倍）
- 変えないもの: 証拠金の上限（資産の 50%）、1 日の損失の上限（3%）。最大の下落での停止は、比べるために外す（今の表と同じ）
- 期間: 先物の 20 年分（2001-01〜2021-05）と、フィリップの 5 年分（2021-06〜）
- 出すもの: 年率・最大の下落・シャープ・最悪の月・最大のレバレッジ

## 3. 選び方（表を見る前に決めた）

- 利用者が、本番のお金で耐えられる最大の下げ X を、**表を見る前に** 決める（実行するときに `--max-dd X` に入れる。
  決めた値はこの章の下に書く）
- 候補 = 20 年分の最大の下落 ≤ X × 2/3、かつ 5 年分の最大の下落 ≤ X × 2/3 の組み合わせ（将来は過去より悪い下げも
  来るので、2/3 にして余裕を取る）
- 候補の中で、20 年分の年率が一番高いもの。年率の差が 0.5% 以内なら、レバレッジの上限の小さい方・1 回の損失の小さい方
- 候補が無ければ今のまま（1 回の損失 1.5%、上限 1 倍）
- 選んだら、最大の下落での停止（今 25%）を X に合わせる
- 選んだ組み合わせでも、本番の始め方（最初の 3 か月は半分）とデモの確認（`docs/operations.md` 12 章）は変えない。
  設定を変えるのは利用者が決めてから、週末に（`./cfd risk` とプリセットの作り直し）

## 4. 注意

- レバレッジを上げるほど、週末や指標の発表で値段が飛んで、損切りより不利な値で決済される損が大きくなる。
  計算は足の始値での約定で値段の飛びを含めているが、過去に無い大きさの飛びは含まれない
- 1 日の損失の上限（3%）は 1 回の損失 4% だと 1 回の損切りで当日の新規が止まる。比べやすさのため変えない
- 試した数（`docs/review.md`）には数えない（新しい売買のルールではなく、張る量の決め方）

## 5. 結果

### 2026-10-23 の結果（Mac。資金 1,000 万円）

X = **30%**（実行のコマンドの `--max-dd 0.30`。説明の例と同じ値なので、本当に耐えられる値かを利用者に確かめる。
違うなら、表はそのままで、選び方だけ新しい X で当てはめ直す）。候補の線は X × 2/3 = 20%

先物の 20 年分（2001-01〜2021-05）: 年率 / 最大の下落 / シャープ / 最大のレバレッジ

| 1 回の損失 | 上限 1 倍（1/2 倍） | 上限 2 倍（2/4 倍） | 上限 4 倍（4/8 倍） |
|---|---|---|---|
| 1.5% | 4.1% / 19.0% / 0.54 / 2.02 | 4.0% / 18.9% / 0.54 / 2.06 | 4.0% / 18.9% / 0.54 / 2.06 |
| 2.0% | 4.8% / 24.6% / 0.52 / 2.10 | 5.3% / 24.7% / 0.54 / 2.72 | 5.3% / 24.7% / 0.54 / 2.72 |
| 3.0% | 4.6% / 33.3% / 0.41 / 2.12 | 7.6% / 35.0% / 0.56 / 3.83 | 7.6% / 35.0% / 0.56 / 3.82 |
| 4.0% | 3.9% / 38.5% / 0.34 / 2.13 | 9.1% / 44.1% / 0.56 / 4.34 | 9.5% / 44.1% / 0.57 / 5.04 |

| 1 回の損失 | 上限 1 倍 | 上限 2 倍 | 上限 4 倍 |
|---|---|---|---|
| 1.5% | 8.1% / 13.5% / 0.82 / 1.66 | 8.1% / 13.5% / 0.82 / 1.66 | 8.1% / 13.5% / 0.82 / 1.66 |

**選んだ組み合わせ: 今のまま（1 回の損失 1.5%・上限 1 倍）**。両方の期間で最大の下落が 20% 以下なのは 1.5% の行だけで、
その中で年率が一番高い（差 0.5% 以内なら小さい上限）。選び方の決まりでは、最大の下落での停止を X（30%）に合わせる
（今 25%。変えるかは利用者が決める）

読み方:
- 上限を上げると、1 回の損失に比例して年率も上がる（20 年分のシャープは 0.54〜0.57 のまま）。上限 1 倍のまま
  1 回の損失だけ上げると、張れずにシャープが下がる（0.54 → 0.34）。上限は 2 倍で足り、4 倍はほとんど変わらない
- 20 年分では、年率 1% ごとに最大の下落がおよそ 5% 増える（4.1% / 19% → 9.1% / 44%）
- X = 30% より大きい下げに耐えられるなら選ぶ組み合わせは変わる（20 年分で 3% × 2 倍なら X ≥ 53%、4% × 2 倍なら X ≥ 66%）

### 2026-10-23 の当てはめ直し: X = 50%

利用者が `--max-dd 0.50` で実行し直した（表は上と同じ）。**X は 30% の結果と表を見た後に選んだ値**で、3 章の
「表を見る前に決める」は守れていない。選び方そのものは変えずに当てはめた。候補の線は X × 2/3 = 33.3%

**選んだ組み合わせ: 1 回の損失 2.0%・上限 1 倍（今のまま）**（20 年分 年率 4.8%・最大の下落 24.6% / 5 年分 年率 10.5%・
17.3%）。候補（両方の期間で 33.3% 以下）は 1.5% の 3 つ・2% の 3 つ・3% × 上限 1 倍。年率が一番高いのは 2% × 上限 2 倍の
5.3% で、差 0.5% 以内の中で上限の小さい 2% × 上限 1 倍（4.8%）になった。決まりでは最大の下落での停止を 50% に合わせる

まだ設定は変えていない（利用者がはっきり頼んだら、週末に `./cfd risk` とプリセットの作り直しで変える）

### 2026-10-23 利用者が決めたこと

- **1 回の損失 2%**（上の当てはめ直しの結果）と、**最大の下落での停止 40%**（決まりの 50% ではなく、2% の 20 年分の
  最大の下落 24.6% の約 1.5 倍。利用者が選んだ）。レバレッジの上限は今のまま（1 銘柄 1 倍・合計 2 倍）
- 変えるのは **本番に移るとき**（`docs/operations.md` 14 章 2）。デモは 1.5%・停止 25% のまま最後まで確かめる
- 本番の始め方は決めてあるとおり、最初の 3 か月は半分（1 回 1%）、問題なければ 2%（15 章 3）
