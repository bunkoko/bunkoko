# 研究の台帳の書き方（D-034）

台本で「〇〇大学の調査では、〜という傾向がありました」と言えるのは、この台帳に人が書いて確かめた研究の一文だけです。AI が覚えている研究や、作った研究は、検査（G1・G3）で止まります。

## 決まり

- 研究は脇役です。古典の一節の読みを補うために使います。主張を補強するためなら、1回に何度使ってもかまいません。古典の章には渡しません（悩みを見る章・まとめ・研究の章・形式C の悩みの章・形式D の比べる章に渡します）。
- **有料の論文（CC BY でないもの）の本文や要旨は、どこにも保存せず、Claude Code・ChatGPT・翻訳サービスなどのクラウドの AI に貼りません。** 台帳に書くのは、書誌と、あなたが本文を読んで自分の言葉で書いた一文・限界・効果の大きさだけです。メモ（note・replication_note）にも論文の文を貼りません。
- license は、論文に書いてある表示で決めます。
  - CC_BY にできるのは、ただの CC BY（4.0 などの版はどれでも）だけです。CC0 は CC0 だけです。この2つの論文は、本文を使ってかまいません。
  - CC BY-NC・CC BY-ND・CC BY-SA・CC BY-NC-ND・CC BY-NC-SA、無料で読めても表示が無いもの、分からないものは、全部 COPYRIGHTED にして、有料の論文と同じに扱います（本文も要旨も保存せず、クラウドの AI に貼りません）。
- 台本で使えるのは、次の全部を満たす行だけです。
  - status が verified
  - verified_from が full_text（論文の本文の「結果」の節で確かめた。要旨や発表文だけなら draft のまま）
  - retraction_checked_at に、取り下げ・訂正を確かめた日がある
  - replication が failed（大きな追試で再現しなかった）でない

## 1行の書き方（config/findings.csv）

| 列 | 書くこと | 例 |
|---|---|---|
| finding_id | FN- で始まる ID | FN-comparison-2019 |
| themes | 合うテーマ（config/themes.yaml の言葉）。2つ以上は `;` で区切る | 嫉妬・比較;承認欲求 |
| claim_ja | 研究の一文。あなたの言葉で、1文・150字まで。最後の「。」は付けなくてよい（付けても外します）。台本にはこのまま入る | 人と比べる時間が長い人ほど、自分の暮らしに満足しにくい傾向がありました |
| limits_ja | 限界。150字まで。台本で一文のすぐあとに添える | アメリカの大学生を調べたもので、働く人にも当てはまるかは分かっていません |
| effect_ja | 効果の大きさ：わずか・小さい・中くらい・大きい（論文に書いてあれば） | 小さい |
| design | theory（考え方）・experiment（実験）・field_experiment（現場での実験）・survey（調査）・longitudinal（長く追いかけた調査）・meta_analysis（多くの研究をまとめた分析）・review（研究のまとめ） | survey |
| population_ja | 調べた人（60字まで）。考え方の論文なら「人を調べた研究ではない」 | アメリカの大学生300人 |
| country | 国 | US |
| affiliation_ja | 語りで言う機関（「〇〇大学の調査では」） | ミシガン大学 |
| authors_ja | 語りで言う著者（機関を言わないとき） | ボリーノら |
| authors・year・title・journal・volume・issue・pages | 書誌（説明欄に載る）。year は西暦4桁の半角数字 | Bolino, M. C.; Turnley, W. H. |
| doi・url | DOI か URL（どちらか）。DOI は 10. で始まる形（https://doi.org/ や doi: を付けて写しても外します）。url は https:// で始まる形 | 10.1002/job.635 |
| license | CC0・CC_BY・COPYRIGHTED | COPYRIGHTED |
| replication | replicated（再現した）・mixed（まちまち）・not_tested（まだ）・failed（再現しなかった） | mixed |
| replication_note | どこで確かめたか（後のメタ分析・追試の論文）。200字まで | 2022年のメタ分析では効果はまちまち |
| retraction_checked_at | 取り下げ・訂正を確かめた日（2026-11-05 の形。論文が出たあと・今日まで） | 2026-11-05 |
| verified_from | full_text・abstract・press_release | full_text |
| checked_by・checked_at | 確かめた人と日 | オーナー・2026-11-05 |
| status | verified・draft | verified |
| note | メモ（200字まで。論文の文を貼らない） | |

- 語りでは、出典が「ミシガン大学の調査（2019年）」のように入ります（affiliation_ja か authors_ja ＋ design の言葉 ＋ 年）。考え方は「ボリーノらが示した考え方（2015年）」、多くの研究をまとめた分析は「ミシガン大学による、多くの研究をまとめた分析（2019年）」、研究のまとめは「ミシガン大学による研究のまとめ（2019年）」になります（大学の公式の考えや、まとめた研究が全部その大学のもののように聞こえないように）。
- 「証明」「必ず」「絶対」「間違いなく」「誰でも」「すべての人」「全ての人」は、一文にも限界にも書けません（読み込みで止まります。限界の「必ずしも〜とは限りません」は書けます。限界は「〜とまでは言えません」「〜かは分かっていません」のように書きます）。
- 一文には、さらに「誰もが」「例外なく」「確実に」「〇%の人」「科学的」「医学的」「明らかになった」「判明」も書けません。
- 実験（experiment・field_experiment）とメタ分析でない研究は、一文に「原因」「せいで」「引き起こす」「もたらす」を書けません。「〜な人ほど、〜な傾向がありました」のように書きます。
- claim_ja と limits_ja は、自分の日本語で書きます（英語の文がそのまま入っていると止まります）。
- 追試がまちまち・まだの研究（mixed・not_tested）は、limits_ja を必ず書きます。

### verified の行に要るもの

- verified_from が full_text（本文の「結果」の節で確かめた）で、replication が failed でない
- population_ja・checked_by・checked_at（2026-11-05 の形）・retraction_checked_at（同じ形。論文の年より後）
- replication が replicated・mixed なら replication_note
- どの行も：finding_id（FN- で始まる）・themes・claim_ja・design・year・authors・title・doi か url・affiliation_ja か authors_ja・license

## 台本での使い方（検査の決まり）

- 台本では「{{finding_src:ID}}では、{{finding:ID}}。」のように、出典の記号と一文の記号を同じ文に書いたときだけ、研究の話ができます。出典の記号だけを書いて、結果を自分で書くことはできません。
- 研究の記号の隣でも、「証明された」「科学的に」「多くの研究」「ほかの研究でも」、専門家・医師・研究者の話は止まります。
- 限界は、次の文で「ただ、調べたのはアメリカの大学生です。」のように、研究の言葉を使わずに添えます（「この研究では」と書くと止まり、研究を外して書き直します）。
- 古典の章では、前の章で使った研究も指せません。
- 研究は、テーマの合うものを ID の順に、悩みを見る章・研究の章・まとめ（形式C は悩みの章・形式D は比べる章）へ1章2つまで渡します。形式A の研究の章は、テーマの合う研究が3つ以上あるときだけできます（悩みを見る章が先に2つ使うため）。
- 研究の章（形式A）は、研究の言葉で止まって直らなければ、章ごと外します（回は止めません）。

## 確かめ方

1. **本文を読む**：論文の「結果」の節で、一文に書くことを確かめます。大学の図書館、自分の購読、著者が公開した原稿（リポジトリ）などで読みます。発表文（プレスリリース）や要旨は、結果を大きく言いがちなので、それだけでは verified にしません。
2. **取り下げ・訂正**：ブラウザで、論文の DOI のページ（出版社のページ）に取り下げ（Retraction）・訂正（Correction）・懸念の表明（Expression of Concern）が付いていないかを見ます。Crossref の検索（search.crossref.org）や Retraction Watch Database でも調べられます。見た日を retraction_checked_at に書きます。
3. **追試**：論文の題で「replication」「meta-analysis」を足して検索し、後の追試やメタ分析で同じ結果が出たかを見ます。社会心理学には、大きな追試で再現しなかった有名な研究（自我消耗・パワーポーズなど）があります。再現しなければ failed にして使いません。
4. **限界**：誰を調べたか（国・年齢・人数）、相関か実験か、効果の大きさを書きます。「関係がある」研究を「原因」とは書きません。理論の論文は design を theory にします（語りでは「考え方」になります）。

## SSD に入れて見る

```sh
cd /Users/bunkoko/koten
uv run koten findings build
uv run koten findings list
```

- `findings build` は、台帳に決まりに合わない行が1つでもあれば、どの行のどこかを出して止まります（1行も入れません）。
- `findings list` は、○（台本で使える）・×（使わない）と、出典・一文・限界・書誌を出します。
- config/findings.csv を消すと、`findings build` は SSD の研究の表を空にします（台帳を正とするため）。
- 企画（`koten plan`）が、テーマの合う研究の一文を章に渡します。台本で使った研究は、確認画面と説明欄（M6）の「この動画で使った研究・データ」に載ります。
- 企画のあとで一文・限界・調べた人・効果の大きさを直したり、使えない状態にしたりすると、台本のときに人の確認（G6）が立ちます。
- `koten script --show` では、研究の段落に【研究｜FN-…】が付き、最後に使った研究の一文・調べた人・追試・限界・効果・書誌が並びます。語りが限界を落としていないか、調べた人より広く言っていないかを、ここで見ます。
