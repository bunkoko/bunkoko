## 0. 今すぐ：SD カードの中身を全部 HDD へ移して、HDD で始める（D-031・D-033）

新しい HDD は `/Volumes/HD-NRLD-A` です。SD カードの中身を、次のように写します。SD カードの中身は、写したあとも消さずに残します（片付けるのは、HDD で問題なく動いたのを確かめてから。下の 8）。

| SD カード | HDD |
|---|---|
| 古典×悩み（koten のデータ） | koten（`/Volumes/HD-NRLD-A/koten`。日本語と × の無い名前にする。D-031） |
| ほかのもの全部 | いちばん上に、同じ名前・同じ並びで（空のフォルダ・リンクも。ファイルとフォルダのタグなどの付帯情報、更新日・作成日もいっしょに写ります） |
| ゴミ箱の中身、Mac と Windows の管理用のもの（.Spotlight-V100 など）、`._` で始まるファイル、.DS_Store、koten backup の控え（koten-backup） | 写さない |

1. 動いている augment と update を止めます。それぞれの窓で Ctrl-C を押します。ここまでの結果は保存され、あとで続きから再開します。

2. SD カードのゴミ箱を見ます。ゴミ箱の中身は写しません。Finder でゴミ箱を開き、SD カードから捨てたもので残したいものがあれば、右クリック →「戻す」で SD カードに戻します。

3. HDD の形式を確かめます。

   ```sh
   diskutil info /Volumes/HD-NRLD-A | grep -E "Personality|Read-Only"
   ```

   - 「File System Personality」が `APFS` か `Journaled HFS+` で、「Volume Read-Only」が `No` なら、4 へ進みます。
   - `NTFS`（買ったときの形式。Mac からは書き込めません）・`ExFAT`・`MS-DOS FAT32`、または NTFS 用の追加のソフトの名前（UFSD_NTFS など）なら、Mac 用に整えます。**HDD の中身は全部消えます**。
     - **先に SD カードを取り出します**。Finder の左の「SDカード」の横の ⏏ を押してから抜きます（間違えて SD カードを消さないため）。
     - `ls -la /Volumes/HD-NRLD-A` で、HDD に残したいものが入っていないことを確かめます。
     - 「ディスクユーティリティ」を開く →「表示」→「すべてのデバイスを表示」
     - 左の一覧の「外部」で、下に HD-NRLD-A がある装置のいちばん上の行を選ぶ（右に「4 TB」と出ることを確かめる）→「消去」
     - 名前：`HD-NRLD-A`（同じ名前にすると、場所が /Volumes/HD-NRLD-A のまま変わりません）、フォーマット：「APFS」（「暗号化」や「大文字/小文字を区別」の付かないもの）、方式：GUID パーティションマップ →「消去」
     - Time Machine に使うかを聞かれたら「使用しない」
     - 消し終えたら、上の diskutil のコマンドをもう一度打ち、`APFS` と `No` が出ることを確かめます。
   - 形式を確かめ忘れても、次の hdd-copy が写す前に形式を見て、合わなければ止まります。

4. SD カードを挿して（3 で取り出したときは挿し直して）、最新を取り込み、SD カードの中身を HDD へ写します。SD カードは挿したままにします。中身の量によって数時間かかります。

   ```sh
   cd /Users/bunkoko/koten
   git pull
   caffeinate -i uv run koten hdd-copy --from "/Volumes/SDカード/古典×悩み" --whole-card 2>&1 | tee -i -a ~/koten-hdd-copy.log
   ```

   - 始めに「数えています」と出ます。数分たってから、写すファイルの数と大きさ、SD カードのいちばん上にあるものの名前、HDD の空きが出て、そのまま写し始めます。並んでいるものが思っていたものと違うときは、Ctrl-C で止めて（SD カードの中身は変わりません）、その画面を Claude に貼ってください。
   - 最後に「前の置き場所（SD カード）はそのまま残します」と出れば終わりです。
   - 止まったときや「写せない」と出たときは、同じコマンドをもう一度打つと続きから写します。写し終えた分は、2回目からは「写し終えています」と出て、写さずに HDD にあるかだけを確かめます。それで大丈夫です。何度打っても同じファイルで止まるときは、その行を Claude に貼ってください。
   - 同じコマンドを2つの窓で同時に打たないでください（2つ目は「ほかの窓で hdd-copy が動いています」と出て止まります）。
   - Mac は電源につなぎ、ふたを開けたままにします。

5. 確かめます。HDD の行が `/Volumes/HD-NRLD-A/koten` で「OK」なら大丈夫です。

   ```sh
   cd /Users/bunkoko/koten
   uv run koten doctor
   ```

   - **これからは、SD カードに新しいものを入れたり、中のファイルを直したりしないでください**（HDD のほうを使います）。ほかのアプリ（写真の取り込みなど）が SD カードの場所を使っていたら、その設定を HDD の場所に変えます。

6. 止めた作業を、HDD で再開します（新しい窓で。数日かかります）。

   ```sh
   cd /Users/bunkoko/koten
   caffeinate -i uv run koten update --index 2>&1 | tee -i -a ~/koten-update.log
   ```

   - 有名な作家と古典の訳を足し、残りの augment（前の分と増えた分）→ 埋め込み → 索引まで、1つで進めます。
   - Mac は電源につなぎ、HDD をつないだまま、ふたを開けたままにします。
   - 進み具合は `tail -n 30 ~/koten-update.log` で見ます。

7. 控えを取ります（週1回。update が動いていても、別の窓で取れます）。

   ```sh
   cd /Users/bunkoko/koten
   uv run koten backup --to "/Volumes/SDカード/koten-backup"
   ```

   - augment・埋め込み（作り直しに日数がかかるもの）・SSD の DB・config の台帳を写します。2回目からは変わったものだけを写します。最後に「控えを … に取りました」と出れば終わりです。
   - SD カードには前の中身が残っているので、空きが足りないと、写す前に「空きが足りません」と出て止まります。そのときは、8 の片付けが済むまで、控えは取らずに進めます（SD カードの「古典×悩み」が、引っ越しの前の控えの代わりになります）。8 で「古典×悩み」を消したあとにこの表示が出たときは、SD カードのものは消さずに、その画面を Claude に貼ってください。
   - 控えは、HDD とは別のドライブに置きます（HDD の中を指すと止まります）。同じコマンドを2つの窓で同時に打つと、2つ目は止まります。
   - 「書き込めません」と出たら、SD カードの横の書き込み禁止のつまみ（LOCK）を確かめます。

8. SD カードを片付けます（HDD で1〜2週間問題なく動いたのを確かめてから）。
   1. 同じコマンドで、SD カードのものが全部 HDD にもあるかを確かめます。2回目なので、もう写しません（HDD で消したり直したりしたものを、SD カードの古いもので戻さないため）。HDD には何も書きません。

      ```sh
      cd /Users/bunkoko/koten
      caffeinate -i uv run koten hdd-copy --from "/Volumes/SDカード/古典×悩み" --whole-card 2>&1 | tee -i -a ~/koten-hdd-copy.log
      ```

      最後に「前の置き場所（SD カード）はそのまま残します」と出たときだけ、次へ進みます。「HDD に無い」「HDD と違う」の行が出て止まったら、何も消さずに、その画面を Claude に貼ってください（HDD で消したり、名前を変えたり、直したりしたものも、この行に出ます）。
   2. まず、SD カードの「古典×悩み」フォルダだけを消します（控えのための空きができます）。Finder で SD カードを開き、「古典×悩み」を選んでから、option キーを押しながら「ファイル」メニューを開き「すぐに削除…」を選びます（⌥⌘⌫）。ゴミ箱は使いません（ゴミ箱を空にすると、Mac のほかの場所から捨てたものも消えます）。「koten-backup」は消しません。
      消したら、すぐに 7 のコマンドで控えを取り、最後に「控えを … に取りました」と出ることを確かめます（それまでは、augment と埋め込みが HDD にしかありません）。それでも「空きが足りません」と出たら、SD カードのほかのものは消さずに、その画面を Claude に貼ってください。
   3. SD カードのほかのもの（写真や書類など）は、入りきるなら SD カードにも残しておくのを勧めます。koten backup が写すのは koten のものだけです。SD カードから消すと HDD にしか無くなり、HDD が壊れると戻せません。消すときは、先に別のドライブかクラウドにも写してください。

### リランカーを試すコマンド（#8）

内蔵 SSD の空きが少ないので、試すモデル（3つで約4GB）は HDD に落とします（HF_HOME）。

1. 評価セットを書き出す。候補のリランカーが上に上げた一節も入れる

   ```sh
   HF_HOME=/Volumes/HD-NRLD-A/hf-cache uv run koten eval export --rerank-model hotchpotch/japanese-reranker-small-v2 --rerank-model cl-nagoya/ruri-v3-reranker-310m --rerank-model BAAI/bge-reranker-v2-m3
   ```

2. tests/eval/retrieval.csv の grade 列に、合う 1・合わない 0 を付ける。grader（Claude の Haiku）にも付けさせる

   ```sh
   uv run koten eval grade
   uv run koten eval agreement
   ```

3. 比べる（LLM の点で見るときは `--by llm` を付ける）

   ```sh
   HF_HOME=/Volumes/HD-NRLD-A/hf-cache uv run koten eval retrieval --rerank-model hotchpotch/japanese-reranker-small-v2 --rerank-model cl-nagoya/ruri-v3-reranker-310m --rerank-model BAAI/bge-reranker-v2-m3
   ```

- 「点の無い一節」（unjudged）がほぼ0の行どうしで比べます。0でなければ、手順1〜2をやり直します（前に付けた点は残ります）。
- いちばん良いモデルを settings.toml の [rerank] model に書くと、本番の検索で使います。本番用のモデルは内蔵 SSD に置きます（検索は HDD を読まない決まりのため）。書いたあと、HF_HOME を付けずに次を1回動かすと、内蔵 SSD に落とします。

   ```sh
   uv run koten retrieve --worry W0001 --explain
   ```

### まだ決めること

#### D-032 写真と BGM を HDD に移すか

- 何が問題か：内蔵 SSD の空きは約10GB です。自分の写真（数百枚で数GB）と BGM を内蔵（~/Pictures/koten-bg・~/Music/koten-bgm）に置くと、空きがさらに減ります。
- 移す：内蔵の空きが守れます。写真を使うのは動画の書き出し（M6）で、HDD を読んでよいバッチの処理なので、困りません。HDD を外していると、写真の枚数を数えられません。
- 移さない：写真アプリから直接入れやすいです。
- 推奨：移す。決まったら、settings.toml の photos_dir・bgm_dir を /Volumes/HD-NRLD-A/media/ の下に変えます。

#### D-028 の残り：画像をどこに使うか（M6 で決める）

- 資料画像カード（一節・背景の章）だけか、写真の足りない所の背景にも使うか、サムネイルにも使うか。

#### 外した作家を足すか（augment が終わってから）

- 小川未明（約480作品）・岡本綺堂・江戸川乱歩・吉川英治・山本周五郎・宮本百合子は、件数か悩みとの相性で外しました（D-025）。容量は問題でなくなったので、制約は augment の時間（1チャンク約5秒）だけです。今の update が終わって、1回の augment にかかる日数が見えてから決めます。
