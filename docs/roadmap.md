### まだ決めること

推奨どおりでよければ、まとめて「推奨どおり」で構いません。

#### D-029 原著者の没年が空の古典の訳（新しく見つかった）

- 何が問題か：青空文庫の与謝野晶子訳『源氏物語』（57件）や尾崎士郎訳『平家物語』は、原著者（紫式部・作者不詳）の没年が作品CSVで空です。そのため、今の権利判定では「判定不能」になり、本文を保存しません。訳者の没年（晶子1942年・尾崎士郎1964年）は満了しています。
- 案1：今のまま使わない。
- 案2：人が確かめた台帳を足す。原著者の時代か没年と、その根拠を書きます。作者不詳の作品は、成立した時代を書きます（著作権法52条で、公表から数えるため）。確かめた分だけ、訳者の没年で判定します。判定の決まりは変えず、空の欄を人が確かめた事実で埋める形です。
- 推奨：案2。源氏・平家の古い訳が使えると、自前の訳（D-023）が大きく減ります。

#### D-023 古文・漢文を自前で今の言葉にした訳に「試訳」と出すか

- 何が問題か：R5 は、外国語の古典を原文から自前で訳したものに「試訳」と出す決まりです。日本の古文や漢文を自前で今の言葉にした場合は決まっていません。
- どのくらい当たるか（見積もり。推測を含む）：
  - すぐ使える古い日本語訳がある：約3割（ただし、この中の佐藤春夫訳の徒然草は青空文庫に見つからず、源氏・平家の訳は D-029 しだい）
  - NDL の画像から人が起こせば使えそう：約2割
  - 西洋の古典：約2割（D-024 で英訳を使う）
  - 自前で今の言葉にする一節：NDL の分を起こせば約2.5割、起こさなければ約4.5割
- 出す：チャンネル独自の訳で、決まった訳ではないと視聴者に分かります。
- 出さない：画面はすっきりします。ただ、AI が下書きした訳が、定まった訳のように見えます。D-024 と違い、元にした訳の出典を書けないためです。
- 推奨：出す。

#### D-020 ほかの電子テキストの扱い（Standard Ebooks・Wikisource・Kanripo・ctext・Perseus）

- 何が問題か：どの電子テキストを、本文の出どころとして DB に入れてよいかです。
  - Standard Ebooks：自分たちが手を入れた部分は CC0 です。元は Gutenberg や影印です。ただ、Perseus や Wikisource（CC BY-SA）を元にした版もあります。
  - Wikisource・Perseus：CC BY-SA です。今の決まり（R2）では本文を保存できません。
  - Kanripo（漢籍）：ライセンスが書かれていません。
  - ctext：規約で自動の取得を禁じているとされます（要確認）。
- 「手がかりだけにすると手間が増える」とは：
  - 論語の白文（漢字だけの原文）やギリシア語の原文は、これらのサイトにあります。でも、そこから写して DB に入れることはしません。
  - 原文が要るときは、保護期間の切れた古い本の画像（NDL の影印など）を見て、人が1字ずつ打ち込みます。その手間のことです。
  - ただ、論語の1章は短く、訓読を書き起こすとき（Mac の #6）に同じページから一緒に起こせます。増える手間は小さいです。
  - ギリシア語の原文は、D-024 で英訳を使うので、当面は要りません。
- 推奨：Standard Ebooks は、元が Gutenberg か影印の版だけを使います（版ごとに巻末の記録で確かめる）。ほかは探す手がかりだけにします。

#### D-027 「参考にした本」の載せ方（アフィリエイト）

- 調べた決まり（公式のページは開けず、写しで確かめた。要確認）：
  - YouTube：アフィリエイトのリンク自体は禁止されていません。専用のアカウントで大量に貼ると、スパムと見られえます。
  - Amazon アソシエイト：決まった文言の表示が要ります。申請から180日で3件売れないと、取り下げられることがあります。
  - ステマ規制（2023年10月から）：直接の対象は広告主です。ただ、Amazon アソシエイトのリンクがどちらに当たるかは灰色です。載せるなら「（広告）」を読める大きさで書きます。
  - 収益化が止まる心配は、リンクよりも「量産型」と見られることのほうがずっと大きいです。
- 選択肢（商業色の弱い順）：
  - A：本を載せない
  - B：説明欄に書誌（書名・著者・出版社・年）だけを書き、リンクは付けない
  - C：説明欄にはブログの参考文献のページへのリンクを1つだけ置き、アフィリエイトはブログにだけ置く
  - D：説明欄に直接アフィリエイトのリンクを置く
- 推奨：B。「胡散臭くしない」に合い、規約の追いかけも要りません。収入が要るようになったら、収益化（YPP）のあとで C を足します。
- 得失：B だと、SPEC の「収益の柱は書籍アフィリとブログ」が当面崩れ、収入は YPP の広告だけになります。決めたら SPEC を書き換えます。

#### D-022 日本語WordNet を、今の意味（M8c）の下書きの材料に使うか

- 日本語WordNet とは：国語辞典ではありません。英語の WordNet の「意味のまとまり」に、日本語の語と、英語の説明を訳した日本語の説明を付けたデータです。NICT が2006年から作り、2.1 が2026-10-24 に出ました。
- 規模：意味のまとまり約6.8万、語約9万、日本語の説明約6.5万。
- ライセンス：目的を問わず無料で使えます。写しには、すべてライセンスの文を付けます。使った回の説明欄には、クレジットを1行入れるのが安全です。
- 質：日本語の説明の約98%は2010年のままです。否定の抜け（「〜がない」が「〜がある」になっている）、誤訳、英語の別の意味の混入があります。区切りは英語のままなので、嫉妬と羨望の違いのような日本語の細かい差は出ません。本音・世間体・億劫などの語はありません。
- 役に立つところ：意味の候補の一覧、同じ意味の語・反対の語・上位の意味、英語の元の説明。
- 推奨：画面に出さず、下書きの材料にだけ使います。人が今の辞書2冊で確かめる段は省きません。入れるには、権利判定に区分を1つ足します（保存はできるが画面には出さない）。

#### D-028 資料の画像の取り先（方針は決まった）

- 使ってよい候補（規約の原文は要確認）：
  - ColBase（国立博物館の所蔵品）：商用可・申請不要・出典が要る。寺社から預かった品（寄託品）は入りません。
  - NDL デジタルコレクションの「インターネット公開（保護期間満了）」：商用可・申請不要。
  - 国書データベースの国文研所蔵分。
  - メトロポリタン美術館・シカゴ美術館・クリーブランド美術館の CC0 の作品。
- 使わない：e国宝（私的利用だけ）、TNM イメージアーカイブ（商用は有料）、大英博物館（非営利だけ）、CC BY-SA・NC の画像。
- 探す道具にだけ使う：ジャパンサーチ・文化遺産オンライン・ウィキメディア・コモンズ（条件は元の館で確かめる）。
- 気をつけること：地獄草紙・九相図・無残絵などは、使えても年齢制限につながりうるので、サムネイルに使いません。
- 決めること：どの取り先を足すか。足すなら、SPEC の資料画像カード（今は NDL のページ画像だけ）と、画像ごとの台帳（取ったページ・権利の表示・確かめた日・出典の文・手を加えたか）を作ります。
- 写真の数：台本の語りの段落は、資料・事実のカードでなければ写真になります。足りない数は Mac の #12 で見ます。

#### D-010 検索結果を並べ直すモデル（リランカー）

- リランカーとは：悩みの文と一節を1組にして読み、合う度合いを1つの数で返す小さなモデルです。文章は書きません。検索で絞った上位50件を並べ直すのに使います。
  - grader とは別のものです。grader は、評価セットの点を後から付ける採点役（既定は Claude の Haiku）です。
  - 台本を書く LLM（Claude）や augment の gemma とも別です。
- 「モデルのライセンス」とは：Hugging Face から落とすリランカーの重みファイルの利用条件です。収益化するので、非営利だけのもの（jina-reranker-v3 の CC BY-NC など）は使えません。MIT や Apache-2.0 なら使えます。
- 候補（どれも MIT か Apache-2.0 とされる。モデルカードは要確認）：
  - hotchpotch/japanese-reranker の small-v2・base-v2（軽い）
  - cl-nagoya/ruri-v3-reranker-310m（日本語の点が高いとの報告）
  - BAAI/bge-reranker-v2-m3（多言語に強い）
- 推奨：Mac で評価の点を付けたあと（#11）、settings の rerank.model を替えて `koten eval retrieval` を1回ずつ回し、良くなったものだけ入れます。
