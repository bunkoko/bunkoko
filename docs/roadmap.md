### リランカーを試すコマンド（#11。augment・埋め込み・索引が終わってから）

1. 評価セットを書き出す。候補のリランカーが上に上げた一節も入れる

   ```sh

   uv run koten eval agreement
   ```

3. 比べる（人の点で。LLM の点で見るときは `--by llm` を付ける）

   ```sh
   uv run koten eval retrieval --rerank-model hotchpotch/japanese-reranker-small-v2 --rerank-model cl-nagoya/ruri-v3-reranker-310m --rerank-model BAAI/bge-reranker-v2-m3
   ```

### まだ決めること

#### D-030 『自省録』の Standard Ebooks 版の元の本文（新しく見つかった）

- 何が問題か：D-020 で、Standard Ebooks は「元が Gutenberg か影印の版だけ」と決めました。確かめ役が版の記録を読んだところ、Long 訳『自省録』の版は「The Internet Classics Archive の打ち込みと、Google Books の画像（影印）をもとにした」版でした。打ち込みの元は Gutenberg ではありません。Legge 訳『論語』の版は Gutenberg と Internet Archive の画像が元で、D-020 に合います。
- 案1：使う。打ち込みは Standard Ebooks が影印と照らして直しています。訳は1862年のもので保護期間が切れており、打ち込みには日本では著作権が生じません。The Internet Classics Archive は CC BY-SA ではありません。
- 案2：使わない。Gutenberg にある Long 訳を、別に取り込む仕組みを作ります（手間がかかります）。
- 推奨：案1。D-020 で避けたかったのは CC BY-SA（Wikisource・Perseus）の条件を引き継ぐことで、この版は当たらないためです。台帳の review_note に「元は The Internet Classics Archive の打ち込みと Google Books の影印。CC BY-SA ではない」と書きます。

#### D-028 の残り：画像をどこに使うか（M6 で決める）

- 決めること：資料画像カード（一節・背景の章）だけに使うか、写真の足りない所の背景にも使うか、サムネイルにも使うか。動画の構成と一緒に、M6 で決めます。
- 画像の台帳とは：使う画像1枚ごとに1行を書く表（CSV）です。M6 で作ります。
  - 書くこと：画像の ID、HDD のファイルの場所、取り先（ColBase など）、取ったページの URL、作品名・作者・年、ページに出ていた権利の表示（「CC0」「パブリックドメイン」「保護期間満了」など）、規約のページと読んだ日、画面と説明欄に出す出典の文、年齢制限につながりうるかの印、確かめた人。
  - 何に役立つか：
    1. 権利の申し立て（YouTube の Content ID など）が来たとき、どこから・どの条件で取ったかをすぐ示せる。
    2. 出典の文を、画面の隅と説明欄にコードで自動で出せる。
    3. 権利の表示が無い画像や、年齢制限の印がある画像を、コードで止められる（印のある画像は、確認画面で人が確かめてから出す）。
    4. 取り先が規約を変えたとき、影響する画像をすぐ見つけられる。
    5. 同じ画像を続けて使いすぎないよう、使った回を数えられる。
  - 書き方：画像を保存するときに1行足すだけです。手間を減らすため、URL を渡すとページの権利の表示を読んで行の下書きを作るコマンドを、M6 で作ることもできます。
- 取り先の例（権利に問題が無いもの）：ColBase、国会図書館デジタルコレクション（保護期間満了）、国書データベース（国文研所蔵分）、メトロポリタン美術館・シカゴ美術館・クリーブランド美術館の CC0。使わないもの：e国宝（個人の利用だけ）、東京国立博物館のイメージアーカイブ（商用は有料）、大英博物館（非営利だけ）、CC BY-SA・NC の画像。
- 写真の数：台本の語りの段落は、資料・事実のカードでなければ写真になります。足りない数は Mac の #12 で見ます。
