# 原文・時代の解釈・試訳・ことばの定義の方針（案）

2026-10-29 作成。オーナーが判断するための案です。リポジトリは何も変えていません。

- 読んだもの：docs/SPEC.md（§3・§6・§7・§8・§13）、CLAUDE.md、docs/background_facts_plan.md、docs/decisions.md、src/koten/license.py、src/koten/script/（placeholders.py・gates.py・data.py）、src/koten/facts/（model.py・store.py）、config/sources.yaml・settings.toml・formats.yaml・prompts/script_v3.md
- 調べ方：このクラウド環境からは、国会図書館（NDL）・文化庁・青空文庫・Gutenberg などのサイトを開けませんでした。直接読めたのは GitHub 上のファイルと Anthropic API の説明ページだけです。それ以外は検索結果の抜粋から読み取ったので、権利や規約の話には「要確認」を付けました。直接読めたものには「確認済み」と書きました。

## 0. 結論

- 3つの要望は、どれも今の権利ルール（R1〜R7）を緩めずに実現できます。
- **著作権のある現代の訳・注釈書・辞書は「照合専用」にします。** オーナーが手持ちの本を読み、結果だけを DB に残します。残すのは「合う・食い違う・触れていない・言い回しが近すぎる」のどれかと、本のページです。本文は保存せず、AI に渡さず、画面にも出しません。
- **明治〜昭和前期の辞書・訓読本・注釈書と、古い英訳は DB に入れられます。** 条件は、関わった人が全員 1967 年までに亡くなっていることです。こうした資料は「その時代の解釈」として、年と出典を添えてそのまま引用できます。NDL の資料は「インターネット公開（保護期間満了）」の表示があるものだけを使います。
- **AI の試訳は3段階で確かめます。** まず AI には、原文と、互いに独立した保護期間満了（以下 PD）の訳・注釈を2つ以上だけ見せて書かせます。次に別の判定役が1文ずつ照らし合わせます。最後に人が現代の本で確かめます。
- **ことばの定義は層に分けます。** 昔の辞書は年を添えてそのまま引用します。今の意味は、自分たちの言葉で書いて確認した1文にします。使われ方は世論調査の数字で、法律上の定義は e-Gov から取ります。LLM は、DB の記号なしに「辞書では」と言えないようにします。
- **順番**：M6（1本を最後まで通す）を先に終えます。そのあと M8 を3つに分けて入れます（§6-4）。

## 1. 3つの要望への答え

### 1-1 AI の訳・解釈を、著作権のある本も使って確かめたい

**できます。ただし、やり方によって法律上の重さが変わります。**

| やり方 | 法律上の見方 | 推奨 |
|---|---|---|
| 人が手持ちの本を読んで確かめる | 著作権は「読むこと」を制限しません。考え・解釈・事実は保護されません（著作権法2条1項1号。江差追分事件 最判平成13年6月28日）。要確認 | **これで始める** |
| 本の文を DB に保存し、AI に照合させる | 30条の4（人が内容を楽しむ目的ではない利用）で許される余地はあります。ただし文化庁は、保存した著作物の表現を出力する目的の RAG には 30条の4 が使えないと整理しています（要確認）。ラベルだけを返す照合なら余地が残る、という読み方で、判例はありません。今の R2 はこの使い方を禁じています | 今はしない |
| クラウドの AI に本の文を送る | 送り先のサーバーに写しができます。今の台本づくりはサブスクリプションの Claude Code（`claude -p`）を使っています。個人向けプランでは、学習を許すと5年、許さないと30日保存されるとされます（要確認）。JapanKnowledge などの有料サービスは、規約で AI への利用を禁じています（要確認） | **しない** |

- 実際のリスクは「読むこと」ではありません。**直したあとの言い回しが現代の訳に近づくこと**です。訳は訳者の著作物（二次的著作物）として、訳者の死後70年保護されます。
- AI の試訳が、有名な現代訳とたまたま似ることもあります。AI は学習で現代訳を読んでいるかもしれず、そうなら似ているだけで問題になりえます（文化庁の考え方。要確認）。**現代の本で確かめる一番の意味は、この「似すぎ」を見つけることです。**
- 背景の事実（facts）では、すでに同じやり方をしています。確かめた出典（fact_sources の `book`）は書誌とページだけを持っています。

### 1-2 明治の辞書・訓読本・注釈書を DB に入れたい（海外の本も）

**入れられます。** 条件は次の4つです。

1. **関わった人全員の没年を確かめる。** 著者・編者・校訂者・訓読者・注釈者・監修・筆録・訳者・序文や解説を書いた人の全員が、1967 年までに亡くなっていること（R3）。外国人は戦時加算も確かめます（R4）。
2. **NDL の表示を確かめる。** 使えるのは「インターネット公開（保護期間満了）」の資料だけです。「（裁定）」「（許諾）」、個人送信、館内限定の資料は使いません（要確認）。
3. **戦後の復刻版は避ける。** 復刻で足された解説や増補は保護されています。元の版を使います。避ける例：ちくま学芸文庫『言海』の解説、『新編大言海』（1982）、『漢文大系』増補版（1972〜77）、講談社学術文庫版の解説、角川『字源』の増補版。
4. **画面では、年と出典を添えてそのまま引用する。** 例：「明治24年の『言海』は…」。AI が言い換えた文を「辞書がこう言った」とは言いません。

海外の資料も同じ扱いです。使える例（どれも要確認）：
- Legge の論語・老子の英訳（Legge は 1897 年没）
- George Long のマルクス・アウレリウス、エピクテトスの英訳（1879 年没）
- A. C. Bradley『シェイクスピア悲劇論』（1935 年没）
- 坪内逍遥のシェイクスピア訳（1935 年没）

使えない例：Lionel Giles（1958 年没・英国）と Arthur Waley（1966 年没・英国）の訳。アメリカでは PD ですが、日本では戦時加算のため保護中と計算されます（Giles は 2039 年ごろまで、Waley は 2047 年ごろまで。要確認）。

### 1-3 言葉の正確な定義を、どこかから取りたい

- 今の辞書の文章を無料で、しかも商用でそのまま使える日本語の資料は、調べた範囲では見つかりませんでした。
- そこで層に分けます（§5）：
  - **昔の辞書**：そのまま引用し、年を添える
  - **今の意味**：自分たちの言葉で書き、今の辞書2冊で人が確かめる
  - **使われ方**：文化庁の世論調査の数字
  - **法律上の定義**：e-Gov
- 今の辞書の文をそのまま引用すること（著作権法32条）も、条件を守れば可能です（要確認）。ただし今は勧めません。

## 2. 資料の5つの区分

| 区分 | 中身 | 例 | 本文の保存 | 索引 | 画面に出す | 台本の AI・判定役に渡す |
|---|---|---|---|---|---|---|
| **S1 原文（PD）** | 古典そのもの | 論語の白文、百人一首、徒然草、Hamlet の英文 | する | する（PD の日本語訳から作った要旨で） | する（R1） | 渡す |
| **S2 時代の解釈（PD）** | PD の訳・訓読・注釈・辞書 | 言海、漢文大系、国訳漢文大成（服部宇之吉訳）、渋沢栄一『論語講義』、下村湖人『現代訳論語』、Legge、Long、坪内逍遥 | する | 訳・注釈はする。辞書は見出しで引く | する（年と出典つき） | 渡す |
| **S3 自前の試訳・語釈** | AI が下書きし、判定役と人の確認を通ったもの | 論語 学而第一の第1章の試訳、語釈、今の意味の1文 | する（SSD） | 要旨づくりに使う | する（「試訳」と明記） | 渡す |
| **S4 照合専用（著作権あり）** | 現代の訳・注釈書・辞書 | 新釈漢文大系、岩波文庫の訳注、日本国語大辞典、大辞林、Waley・Gummere の英訳 | **しない**（書誌・ページ・人の判定だけ） | しない | しない（説明欄の参考文献には書ける） | **渡さない** |
| **S5 手がかり** | 探すためだけに使う | ウィキペディア（D-013 の例外）、ウィクショナリー、ctext、Kanripo、zh.wikisource、Perseus、Folger | しない（ウィキペディアだけは今の例外どおり） | しない | しない | 渡さない |

区分ごとの注意：
- **S1**：原文は、PD の影印や活字本から人が確定し、底本とページを記録します。現代の校訂本の句読点・校訂に権利があるかは、日本では判例が見つかりませんでした。中国と韓国では保護された例があります（要確認）。なので PD の資料から取ります。
- **S2**：現代の学者による書き下しは、新しい著作物になりえます。将門記訓読文事件（東京地判昭和57年3月8日）で、学者の訓読が二次的著作物とされました（判決文は未読。要確認）。明治・大正の訓読本も、訓読者と校訂者の全員の没年を見ます。
- **S3**：AI が書いた書き下しも試訳と同じ扱いにし、「試訳（書き下しも当チャンネル）」と表示します。
- **S4**：使う本は、自分で持っている本か図書館で借りた本だけにします。使用目的を限っている有料サービスや、DRM 付きの電子書籍の文は使いません。DRM（コピー防止）を外すことは侵害とみなされます（著作権法113条。項の番号は要確認）。
- **S4 と書籍アフィリ**：確かめに使った本は、説明欄の「参考にした本」に載せられます。SPEC §3 が収益の柱にしている書籍アフィリにもつながります。語りでは、S4 の書名や訳者名は出しません。

## 3. データの持ち方

### 3-1 一節の通し番号（passage_key）

訳・注釈・辞書を同じ一節に結び付けるため、`<作品記号>:<番号>` の形の共通の番号を振ります。

| 作品 | 番号の付け方 | 例 | 注意 |
|---|---|---|---|
| 論語 | 篇.章 | `lunyu:1.1`（学而第一の第1章） | 章の分け方は版によって少し違う。どの版の分け方かを記録する |
| 孟子 | 篇.上下.章 | `mengzi:1a.1` | |
| 老子 | 章 | `laozi:1` | 81章 |
| 荘子 | 篇.段 | `zhuangzi:2.3` | 段は自分たちで分ける |
| 百人一首 | 歌番号 | `hyakunin:35` | |
| 徒然草 | 段（序段は0） | `tsurezure:7` | |
| 方丈記 | 段 | `hojoki:1` | 段は自分たちで分ける |
| 万葉集 | 国歌大観の番号 | `manyo:<番号>` | |
| マルクス・アウレリウス『自省録』 | 巻.節 | `meditations:2.1` | |
| エピクテトス『提要』 | 章 | `enchiridion:1` | |
| セネカ『倫理書簡』 | 書簡.段落 | `seneca_ep:1.1` | |
| シェイクスピア | 幕.場.台詞の順番 | `hamlet:3.1.12` | 行番号は版によって違うので、底本での台詞の順番を使う |
| 辞書 | 見出し語・読み・語義番号＋辞書の版 | 『言海』の「ふつう」第1義 | 年とページを必ず持つ |

注釈が何章かをまとめて扱う場合もあるので、範囲（from〜to）でも結び付けられるようにします。

### 3-2 新しい表と置き場所

**HDD（大きな元データ。検索・API の処理中は読まない）**
- `raw/ndl/<PID>/`：OCR の JSON、使うページの画像（IIIF）、manifest
- `raw/gutenberg/`・`raw/standardebooks/`・`raw/wordnet/`・`raw/ndlngram/`
- `clean/ref/renderings.parquet`：すべての版の本文（OCR のまま、まだ確かめていないものも含む）
- `ocr2/`：NDLOCR-Lite で読み直した結果

**SSD（SQLite。台本づくりはここだけを読む）**

| 表 | 主な列 | 用途 |
|---|---|---|
| ref_works | 資料ID、区分（S1・S2・S4）、書名、版、刊行年、出版者、PID・URL、関わった人（役割・没年・国籍）、license、判定の理由、NDL の公開範囲と読んだ日、based_on（元にした資料） | 資料と権利判定 |
| canon | 作品記号、書名、原語、番号の付け方、番号の出どころ | 古典の作品 |
| passages | passage_key、作品記号、見出し（例：学而第一 第1章）、並び順 | 一節の通し番号 |
| renderings | 版ID、passage_key（範囲可）、資料ID、役割（原文・訓読・訳・注釈）、言語、確認済みの本文、表示用の本文（「表記を改めた」の印）、年、解釈した人、底本の場所（PID・コマ・座標、または章・ページ）、状態、確かめた人と日、文の指紋 | 一節ごとの原文・訓読・訳・注釈（確認済みのものだけ写す） |
| dict_entries | 見出しID、見出し語、読み、語義番号、確認済みの本文（そのまま）、資料ID、刊行年、PID・コマ・座標、状態、確かめた人と日、文の指紋 | 昔の辞書の語釈 |
| shiyaku | 試訳ID、passage_key、種類（現代語訳・書き下し・語釈・解釈の分かれ目）、本文、根拠にした版ID、重訳の元（例：Long の英訳）、状態、判定役の結果、人の照合の要約、文の指紋 | 自前の試訳（S3） |
| glosses | ID、見出し語、読み、語義番号、自分たちの言葉の1文、下書きの材料（WordNet の ID・Wikidata の L 番号・昔の辞書）、状態、確かめた人と日 | 今の意味（S3） |
| ref_books | ID、書名、著者・訳者・注釈者、出版者、版・刷、年、ISBN、持ち方（自分の本・図書館）、license は常に COPYRIGHTED、説明欄に出すか、アフィリの検索語 | 照合専用の本（S4）。SPEC §7 の references 表を広げたもの |
| checks | ID、対象（試訳ID・今の意味のID）、確かめた主張の番号、ref_books の ID、ページ、判定（一致・食い違い・触れていない・言い回しが近い）、どう直したか（自分の言葉で60字以内）、確かめた人と日 | 照合の記録 |

- **ref_books には本文の列を作りません。** 表の形の上で、S4 の文を保存できないようにします。
- **checks のメモ欄も、本の文を書く場所にはしません。** 書くのは「ページ」と「自分の言葉で、どう直したか」だけです。

### 3-3 今の仕組みとのつなぎ方

- **検索**：S1・S2 の日本語（PD の訳・注釈）から augment で要旨・テーマ・悩みを作り、`canon:<passage_key>` の候補として今の候補表に入れます。漢文・英語の原文は埋め込みません（SPEC §8.4 と同じ）。
- **候補の中身**：quote_text は原文（S1）です。その日本語の読みとして、承認済みの試訳か、出典つきの PD の日本語訳を持たせます。
- **試訳はオンデマンドで作ります。** 企画で選ばれた一節だけを作り、前もって全部は訳しません。同じ一節を2回目に使うときは、確認済みのものをそのまま使えます。
- **G2（ライセンス）**：今は日本語以外の一節を一律に不合格にしています。これを「承認済みの試訳か PD の日本語訳が付いていれば合格」に変えます。
- **背景の事実（facts）**はそのまま使います。資料の刊行年や著者は、ref_works から自動の事実にもできます。

## 4. AI の試訳と解釈の作り方・確かめ方

### 4-1 全体の流れ

```
① 原文を決める（S1）     PD の影印・活字本から人が確定。底本とページを記録
② 時代の解釈を集める（S2） 互いに独立した PD の訓読・訳・注釈を2つ以上。OCR を人が直す
③ AI が下書き（S3）       原文と S2 だけを見て、書き下し・現代語訳・語釈・解釈の分かれ目を書く
④ 機械の確かめ           記号・数・固有名の一致、「」の作り話、S2 の丸写しがないか
⑤ 判定役                 1文ずつ、どの S2 が支えるかを返す。根拠のない文は書き直し
⑥ 人の照合（S4）          手持ちの現代の本で、主張ごとに判定を付ける
⑦ 承認                   approved になると、台本で {{shiyaku:}} が使える
```

### 4-2 AI に見せるもの・見せないもの

| 役 | モデル | 見せる | 見せない |
|---|---|---|---|
| 試訳の下書き | 台本と同じ Claude（`claude -p`） | S1、選んだ S2、PD の辞書の見出し | S4・S5 |
| 試訳の判定役 | 別の呼び出し。できれば別のモデル（例：sonnet） | S1、S2、下書き | S4・S5、下書きの経緯 |
| 台本 | 今と同じ | S1、承認済みの S3、引用する S2、今の意味、事実 | S4・S5 |
| G3 の判定 | 今と同じ | 同上 | S4・S5 |
| （段階Bのときだけ）ローカルの照合 | Ollama（gemma4:26b など） | S3 の主張1つと、S4 の該当箇所1つ | それ以外すべて。出力はラベルだけ |

- 下書きのプロンプトには「現代の出版物の訳を思い出して使わない」と書きます。ただし、守られたかを AI 自身では確かめられません。なので⑥の人の照合で「近すぎ」を見ます。
- S1〜S3 はすべて PD か自前の文なので、クラウドの Claude に送っても権利の問題はありません。

### 4-3 判定役：互いに独立した PD の版と比べる

- **比べる版は2つ以上。** 例（論語）：
  - 『漢文大系』の訓点と安井衡『論語集説』の注
  - 『国訳漢文大成』（服部宇之吉訳）
  - 下村湖人『現代訳論語』（青空文庫）
  - Legge の英訳
- **元にした資料を based_on に記録します。** 渋沢『論語講義』は三島中洲の講義を多く使ったとされます（要確認）。両方を使うときは、独立した版としては1つと数えます。
- **判定役が1文ずつ返すもの**：その文を支える版、読みが違う版、判定（支持あり・分かれる・根拠なし）。合否はコードが決めます（今の judge_v2 と同じ形）。
  - 「根拠なし」：書き直し（2回まで）。直らなければ人の確認へ
  - 「分かれる」：試訳に「解釈が分かれる」の印を付けます。語りでは、一方に決めつけない言い方にします
- **機械の確かめ**：試訳が S2 のどれかと12字以上同じ並びなら、それは自前の訳ではありません。その PD の訳を出典つきで使うか、書き直します。PD なので法律上の問題はありませんが、「試訳」と名乗るのが正しくなくなるためです。書き下しの決まった言い回し（〜ずや・〜と謂ふ など）と固有名は数えません。

### 4-4 著作権のある現代の本（S4）での確かめ方

**段階A（推奨。今の規則のままでできる）**

1. `koten shiyaku sheet --passage lunyu:1.1` が照合票（HTML と CSV）を出します。欄は、主張の番号、試訳の文、確かめる本（ref_books から）、ページ、判定です。本の文章を書く欄は作りません。
2. オーナーが本を開いて読み、判定を付けます。
   - 食い違いがあれば、自分の言葉で直します。本の言い回しは写しません。目安は「同じ並びが12〜15字以上続いたら書き直す」です。
   - 判定は「言い回しが近い（近すぎ）」も付けます。
3. 1つの一節につき、現代の本を1冊以上、できれば2冊で確かめます。今の意味（§5）は2冊で確かめます。
4. `koten shiyaku accept` で checks に入れます。食い違いが残っているあいだは approved にしません。

**段階B（任意。規則を足し、弁護士の意見をもらってから）**

- **B1 その場で照合する（保存しない）**：オーナーが手持ちの本の該当箇所をその場で入力するか、読み取ります。ローカルの Ollama が、判定のラベルと「似ている度合い（数字）」だけを返します。入力した文と読み取った画像は、終わったら消します。
- **B2 抜き書きを保存する**：使う一節の分だけを、別の暗号化した SQLite に置きます。索引にはせず、台本の AI・判定役・`koten serve`・`--show`・書き出しには渡しません。ログには指紋だけを残し、全部を消すコマンドを用意します。
- **B1・B2 に共通する決まり**：
  - 理由の文章は書かせない（言い換えの形で本の表現が漏れるため）
  - 出力に本の文が8〜10字以上続けて入っていたら捨てる
  - クラウドの AI は使わない
  - 有料サービスや電子書籍（DRM）からは取らない
- **法的な根拠**：30条の4（非享受）です。「ラベルだけなら許される余地がある」という読み方で、判例はありません。読売新聞は 2025-08-07 に、日経と朝日は 2025-08-26 に Perplexity を訴えましたが、判決は見つかっていません（要確認）。
- **推奨**：B1 は、段階A を20〜30回分回して手間が重いと分かってから考えます。B2 は勧めません。

### 4-5 状態の流れ

| もの | 状態 | 使えるもの |
|---|---|---|
| 試訳（shiyaku） | draft → checked（機械）→ judged（判定役）→ human_checked（S4 で照合）→ approved。横道として disputed（食い違いが残る）と rejected | approved だけ |
| S2 の版・辞書の見出し | ocr → transcribed（人が直した）→ verified（画像と照合した） | verified だけ |
| 今の意味（glosses） | draft → checked（今の辞書2冊で照合）→ approved | approved だけ |

- 文が変わったときは、文の指紋で気づけるようにします。企画のあとで変わった回は G6（人の確認）へ回します。今の facts と同じ仕組みです。
- 試訳や NDL 由来の文を含む回は、これまでどおり G6 で review_required にします。

### 4-6 語りで言ってよいこと・言えないこと

**言ってよい**
- 「ここからは当チャンネルの試訳です」。画面の「試訳」の表示はコードが自動で付けます（R5）。
- 「{{interp_src:…}}の訓読では、「{{interp:…}}」と読みます」。差し込むと「明治42年の『漢文大系』の訓読では…」のようになります。
- 「この一文は、読み方が分かれています」。試訳に「分かれる」の印があるときだけ言えます。
- 「明治の人はこう読みました。今の私たちは、こうも読めます」。解釈だと分かる言い方にします（今の script_v3 と同じ決まり）。

**言えない**
- 「通説では」「多くの学者は」「研究では」「本来の意味は」「語源は」（DB の記号がない場合）
- 現代の本（S4）の書名や訳者名を出して、「○○訳ではこう」と言うこと
- AI が言い換えた文を、「辞書や注釈がこう言った」として出すこと

## 5. ことばの定義

### 5-1 層

| 層 | 何を言うか | 出どころ | 画面 | 記号 |
|---|---|---|---|---|
| **A 昔の辞書** | 「明治24年の『言海』は…と説明しています」 | 言海・日本大辞書・言泉・大日本国語辞典・辞林と広辞林（1934 年まで）・字源（1923）（S2） | そのまま引用し、ページの画像も出す | `{{def:}}`・`{{def_src:}}` |
| **B 今の意味** | 「今の国語辞典では、おおむね…と説明されています」 | 自分たちの言葉で書いた1文（S3）。下書きの材料は Wikidata の語彙データ・日本語WordNet・A の辞書。人が今の辞書2冊で確かめる | 文字で出せる。ただし辞書からの引用のようには見せない | `{{gloss:}}` |
| **C 使われ方の数字** | 「本来の意味で使う人は○%」 | 文化庁「国語に関する世論調査」 | グラフ | `{{stat:}}`（今の仕組みのまま） |
| **D 法律上の定義** | 「法律では…と定めています」 | e-Gov 法令API Version 2 | そのまま出し、「法律上の定義」と表示 | `{{law:}}`・`{{law_src:}}` |
| **E 言葉の歴史の数字**（任意） | 「明治から昭和で、この語が本に出る回数」 | NDL の Ngram データ（ndlngramdata） | グラフ | `{{stat:}}` |
| **F 今の辞書をそのまま引用**（今はしない） | 32条の引用 | 手持ちの辞書 | 1回に1つまで | なし |

- **B の言い方は、確かめた冊数に合わせます。** 2冊が合っていれば「おおむね」、3冊以上なら「多くは」。今の辞書の書名は言いません。
- B の文は、1冊の辞書の語義の並びや言い回しをなぞらないようにします。2冊以上と Wikidata・WordNet の材料から、一般的な言い方で書きます。
- **D は法律相談の形にしません**（除外カテゴリ）。使うのは「労働者」「成年」のような語の、意味の説明だけです。
- **F の条件（要確認）**：
  - その辞書の言葉づかいそのものを論じる必要があること
  - 「」で囲み、画面でも区別すること
  - 自分たちの語りが主で、引用が従であること
  - 出典（辞書名・版・出版社・見出し）を画面と説明欄に出すこと
  - 一字も変えないこと
  - 1回に1つまでで、タイトル・サムネイル・ページの写真には使わないこと

ページの画像は自分たちで用意した素材になります。量産型と判定されないための対策（SPEC §3）にも役立ちます。

### 5-4 新しい記号と G1 の決まり

**記号**（どれも DB の値を機械的に差し込みます。R6）
- `{{def:ID}}`：昔の辞書の語釈（そのまま）
- `{{def_src:ID}}`：出典。例「明治24年の大槻文彦『言海』」
- `{{gloss:ID}}`：今の意味の確認済みの1文（文ごと差し込む）
- `{{interp:ID}}`：時代の解釈（訓読・訳・注釈）をそのまま
- `{{interp_src:ID}}`：その出典
- `{{shiyaku:ID}}`：承認済みの試訳（今の `{{quote_ja:}}` をこれに置き換える）
- `{{law:ID}}`：法律上の定義。出典は `{{law_src:ID}}`

**G1 に足す決まり**
1. 「辞書・辞典・字書・字典・字引・国語辞典・英和・dictionary」を含む語りの段落には、`{{def:}}` か `{{gloss:}}` が必要です。
2. 「訓読・書き下し・注釈・注では・訳では・学者・研究者・本来の意味・もともとの意味・語源・原義」を含む段落には、`{{interp:}}`・`{{shiyaku:}}`・`{{gloss:}}`・`{{def:}}` のどれかが必要です。「通説・定説・諸説・多くの学者」は使えないことにします。
3. 辞書・注釈書・現代の本の名前を直接書いたら不合格です。対象は ref_works と ref_books の書名と、広辞苑・大辞林などの固定の一覧です。S4 の書名には記号もないので、語りには出せません。
4. 「」の中に入れてよいものに、`{{def:}}`・`{{interp:}}`・`{{shiyaku:}}`・`{{law:}}` を足します。1の言葉がある段落では、10字以下の短い「」も許しません。
5. `{{def:}}` と `{{interp:}}` の近くには、`{{def_src:}}`・`{{interp_src:}}` が必要です（出典のない引用を防ぐ。R7）。
6. 試訳の段落の「試訳」の表示はコードが付けます。台本の AI には書かせません。

**G2・G3・G6**
- G2：`{{def:}}`・`{{interp:}}` の資料が使用可（PD_JP など）か、`{{shiyaku:}}` が approved かを見ます。
- G3：判定役に、その章の def・gloss・interp・shiyaku を DB の値として見せます。1文ずつの判定（judge_v2）に「定義の文」の種類を足し、根拠の ID がない定義の文は不合格にします。
- G6：試訳・NDL 由来の文・団体名義の資料を含む回は、人の確認へ回します。

### 6-2 NDL の流れ（使う分だけ取る）

1. オーナーが NDL のサイトで資料を開き、表示が「インターネット公開（保護期間満了）」かを確かめます。奥付から関わった人を書き出し、Web NDL Authorities で没年を調べて、config/ref_works.csv に書きます。
2. `koten ref check` が、license.py で全員を判定します。NDL の表示と比べて、厳しいほうの結果を採ります。
3. `koten ref fetch --pid …` が、OCR の JSON と目次を HDD に取ります（net.py を通し、1秒1件以下）。
4. 使う見出しや一節が決まったら、`koten ref locate` がページを探します。辞書は五十音と OCR の見出しから、漢籍は篇・章の見出しから探します。そのページの画像だけを取ります。
5. NDLOCR-Lite（CC BY 4.0。Apple シリコンで動く。確認済み）で読み直し、2つの OCR が食い違う所に印を付けます。
6. 確認画面（画像と本文を左右に並べた HTML）で、人が直します。返り点と送り仮名は人が入れます。旧字を新字に直したときは「表記を改めた」の印を付けます。
7. `koten ref accept` で、確かめた本文を SSD に入れます。

OCR の精度：NDLOCR ver.2.1 の文字の F 値は、1870年代の人文書で 0.921、1880年代で 0.957 です（確認済み）。辞書の多段組や漢文の訓点はもっと悪くなる見込みなので、引用する文は必ず人が画像と照らし合わせます。

### 6-3 手間の目安（見込み）

| 作業 | 1件あたり |
|---|---|
| 資料1冊の権利の確認（関わった人の没年と NDL の表示） | 15〜30分 |
| 辞書の見出し1つ（OCR を直し、画像と照らし合わせる） | 5〜10分 |
| 漢文の1章（白文を確定し、PD の訓読・注1〜2種を直す） | 20〜40分 |
| 試訳の照合（現代の本1〜2冊） | 15〜30分 |
| 今の意味の1文（辞書2冊） | 10分 |

1回の動画に新しい古典の一節が2つと、ことばが1つ入るなら、最初は2〜3時間かかる見込みです。確認済みの一節は次から使い回せるので、DB にたまるほど手間は減ります。人の手が入ることは、量産型と判定されないための対策にもなります。

## 7. license.py と規則の変更（どれも厳しくする方向）

- **没年で判定する人を広げます。** 今は著者と訳者だけで、編者・校訂者は青空文庫のフラグに任せています。NDL と Gutenberg の資料では、編者・校訂者・訓読者・訓点者・注釈者・監修・筆録・序文や解説を書いた人・増補した人も、全員を判定します。
- **戦時加算（R4）を国ごとの日数で計算します。**
  - アメリカ・イギリスなどは 3,794 日です。この場合、1957 年に亡くなった人は 2018-05-21 に保護が切れているので、今の境界の 1958 年で合います。
  - ギリシャは 4,180 日です。1957 年に亡くなった人でも 2019-06-11 まで保護が残り、そのあいだに保護期間の延長がかかるので、今も保護中という計算になります（要確認）。
  - 国ごとの日数の表を持ち、日数が分からない国（レバノン・スリランカ・パキスタン）と国籍が分からない人は、最大の日数で計算します。
- **R4 の確認の結論を書いておきます。** 連合国籍で 1958〜1967 年に亡くなった人の、1941-12-08 より前の作品は、確認すれば実際には COPYRIGHTED になります。
- **NDL の表示を2つ目の関門にします。** license.py の結果と比べて、厳しいほうを採ります。
- **戦後の復刻版や増補版**は、新しく加わった人も判定に入れます。
- **団体名義の作品**（三省堂編輯所など）は没年がないので、今は UNKNOWN になります。扱いは §8 の D-018 で決めます。
- **ref_books（S4）**は常に COPYRIGHTED です。本文の列は持ちません。
- **WordNet を保存する場合**は、新しいライセンスの値が要ります。今の `may_store_text` は PD_JP・CC0・CC_BY しか認めていないためです（D-022）。

## 11. 審査で見つかった直し（この案を実装する前に反映する）

辛口の審査役が、この案を読み直して見つけた点です。実装のときは、上の本文よりこちらを優先します。

**作り話が動画に出る穴**
- **今の意味の層 B の言い方**：「今の国語辞典では、おおむね…」は、自分たちの文を辞書の説明のように見せてしまいます。「ここでは『普通』を…という意味で考えます」「辞書の説明を私たちなりにまとめると…」のように、自分の言葉だと分かる言い方にします。「辞書では」と言えるのは、昔の辞書をそのまま引く層 A（と、もし使うなら層 F）だけにします。
- **一節の意味の主張**：「当時、君子とは為政者のこと」「孔子が言いたかったのは」のような文は、今の G1 の言葉では見つけられません。判定（judge_v2）に「一節の意味の主張」の種類を足し、承認済みの試訳か時代の解釈（interp）の ID を根拠に求めます。語り手自身の読みは「私はこう読みたい」と、意見だと分かる形にします。「明治の人は」ではなく「明治42年の『漢文大系』の訓読では」と、資料の名前で言います。
- **「独立した2つの版」**：論語の明治の訳や Legge の英訳の多くは、朱子の注（新注）に沿っているとされます（未確認）。同じ流れの版が2つ合っても、確かめたことにはなりません。based_on に注の流れ（古注・新注・徂徠 など）を記録し、2つ以上の流れで支持があるときだけ「支持あり」と数えます。「読み方が分かれる」の印は、人が確かめてから付けます。
- **タイトル**：「本当の意味」「語源」「辞書では」をタイトルでも止めます。

**法律の見積もりが甘い所**
- **AI の試訳が現代の訳に似てしまう危険**：手持ちの1〜2冊で確かめても、ほかの何十もの現代訳との「似すぎ」は見つけられません。そこで次のようにします。
  - PD の日本語訳がある一節は、それを出典つきでそのまま使う。試訳は、読める PD の訳が無いときだけにする
  - 書き下しは、PD の訓点（『漢文大系』など）から機械的に作り、「書き下しは『漢文大系』の訓点による」と書く
  - 和歌には、整った現代語訳のかたまりを付けない（短い訳は、出版された通釈と似やすい）
- **「12〜15字」は法律の線ではない**：似ているかの判断は、言い回しや組み立ての選び方が共通しているかで決まります。字数はふるい分けの目安だけにし、長さに対する割合で見ます。直すときは、現代の言い回しを直すのではなく、原文と2つ以上の PD の資料から書き直します。
- **「保存しない」照合（B1）も写しを作る**：本の文を入力したり読み取ったりすること自体が複製です。業務での利用は私的使用（30条）に入らないので、B1 も B2 と同じく 30条の4 に頼ることになります。B1 は「さらされる範囲が小さい」だけで、新しい規則と弁護士の意見が先に要ります。
- **戦時加算（R4）**：国ごとの日数がまだ確かめられていません。国によっては日数が長く、1955〜57年に亡くなった人でも保護が残る計算になりえます。そこで、連合国籍か国籍の分からない人で 1955〜1957 年に亡くなった人は、文化庁の表を読むまで NEEDS_REVIEW にします。権利を 1941-12-08 に持っていたのが出版社（英米など）の場合もあるので、その場合も確認に回します。

**権利の判定**
- **団体名義の扱い（D-018）**：2つの場合を分けます。
  - 『漢文大系』『漢籍国字解全書』のように、校訂者や注釈者の名前が出ているもの：その人たちの没年で決めます。
  - 平凡社『大辞典』・三省堂『漢和大字典』のように、団体の名前だけで公表されたもの：公表から数えます（著作権法53条）。
  - 著作物に出ている名義と、関わった人を分けて記録します。
- **確かめていない話**：次の話は検索の抜粋で見ただけなので、要確認にします。
  - 「下村湖人『現代訳論語』は青空文庫にある」
  - 「『国訳漢文大成』の論語は服部宇之吉の訳」：後の刷りで別の人が補った可能性があります。宇野哲人（1974年没）が訳した巻もあります。
  - 使う刷りの奥付で確かめます。
- **Pascal の英訳**：訳者 W. F. Trotter の没年が分かっていないので、確かめるまで使いません。
- **『言海』の年**：『言海』は4冊を1889〜1891年に出し、その後も直しながら刷り直されています。「明治24年の『言海』」と言えるのは、第4冊の初刷りだけです。出典には、取り込んだ PID の刷りの年・冊・コマを入れます。
- **法令と自前の文のライセンス**：法令（著作権法13条で保護されない）と自前の文は、今の G2 の値（PD_JP・CC0・CC_BY）のどれにも当たりません。NOT_PROTECTED_ART13・OWN のような値を足します（緩める変更ではありません）。
- **将門記訓読文事件**：判決文をまだ読んでいないので要確認にします。ただし「今の学者の書き下しは保護されるものとして扱う」という決まりは、この判決が無くても変えません。
