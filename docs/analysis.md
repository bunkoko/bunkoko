# 分析の設計（ドラフト v0.1）

[要件定義書](./requirements.md) の「5.2 睡眠指標」「5.3 環境指標」「5.5 分析と気づき」を具体的にしたもの。
部屋の環境に加えて、**Apple Watch で取れる睡眠以外のデータ**（心臓・呼吸・体温・活動・運動・光・心の状態など）も使う。

- 「[TBD]」は未確定、「[要確認]」は実機や公式資料で確かめる項目。

## 1. 基本の考え方

### 1.1 「1日のサイクル」で見る
睡眠だけを切り出すのではなく、**日中 → 寝る前 → 睡眠 → 翌日** を1つのサイクルとして見る。

```
  日中              寝る前2時間         睡眠中             翌朝・翌日
 ─────────────── ─────────────── ─────────────── ───────────────
 日光・運動・歩数   照明・入浴・CO2     睡眠ステージ        体感（手入力）
 カフェイン・気分   運動の終了時刻      心拍・HRV・呼吸     安静時心拍・HRV
 座りっぱなし       飲酒               手首皮膚温・CO2     歩数・運動・気分
        └──────── 要因（原因の候補）─────────┘ └──── 結果 ────┘
```

このため、Apple Watch のデータには3つの役割がある。

| 役割 | 意味 | 例 |
|---|---|---|
| **要因** | 睡眠に影響しそうなもの | 日光を浴びた時間、運動、カフェイン、飲酒、寝る前の心拍 |
| **結果** | 睡眠のよしあし、その翌日の状態 | 睡眠ステージ、睡眠中の HRV、翌朝の安静時心拍、翌日の歩数・気分 |
| **基準線** | 「いつもの自分」の値。いつもとの差を見る | 安静時心拍・HRV・呼吸数・手首皮膚温の28日間の値 |

### 1.2 毎朝、自動で計算する
1. 起きると、iPhone アプリが HealthKit のデータをサーバーに送る（部屋のデータは5分ごとにすでに溜まっている）
2. サーバーが「1晩」を区切り、前日の日中から翌朝までをまとめた **1日 = 1行の表** を作る
3. 個人の基準線を更新し、いつもとの差を計算する
4. 条件別の比較などを行い、朝のレポート・寝る前の提案に使う

## 2. 使うデータ

### 2.1 Apple Watch / iPhone（HealthKit）
| 区分 | データ | HealthKit の型 | 役割 | 優先度 | 条件 |
|---|---|---|---|---|---|
| 睡眠 | 睡眠ステージ | `sleepAnalysis` | 結果 | Must | watchOS 9 以降 |
| 心臓 | 心拍数 | `heartRate` | 結果（睡眠中）・要因（寝る前） | Must | — |
| 心臓 | 安静時心拍数 | `restingHeartRate` | 結果（翌日）・基準線 | Must | — |
| 心臓 | 心拍変動（HRV） | `heartRateVariabilitySDNN` | 結果・基準線 | Must | 測る回数が少なく、ばらつきが大きい |
| 心臓 | 歩行時の平均心拍数 | `walkingHeartRateAverage` | 基準線 | Could | — |
| 心臓 | 心拍数の回復（運動後1分） | `heartRateRecoveryOneMinute` | 結果（翌日）・基準線 | Could | ワークアウトを記録した日だけ |
| 呼吸 | 呼吸数（睡眠中） | `respiratoryRate` | 結果・基準線 | Should | — |
| 呼吸 | 血中酸素 | `oxygenSaturation` | 結果（参考） | Could | 対応機種・地域のみ |
| 呼吸 | 呼吸の乱れ（睡眠中） | `appleSleepingBreathingDisturbances` | 結果（参考） | Could | 対応機種のみ。値の推移を見るだけで、判定はしない |
| 体温 | 手首皮膚温（睡眠中） | `appleSleepingWristTemperature` | 結果・基準線 | Should | Series 8 以降 / Ultra |
| 活動 | 歩数・移動距離・上った階数 | `stepCount` / `distanceWalkingRunning` / `flightsClimbed` | 要因・結果（翌日） | Must | — |
| 活動 | アクティブカロリー | `activeEnergyBurned` | 要因 | Should | — |
| 活動 | エクササイズ・スタンドの時間 | `appleExerciseTime` / `appleStandTime` | 要因 | Must | — |
| 運動 | ワークアウト（種類・時刻・長さ・心拍） | `HKWorkout` | 要因（量と、寝る前何時間か） | Must | — |
| 運動 | 運動の強さ（運動強度スコア） | `workoutEffortScore` / `estimatedWorkoutEffortScore` / `physicalEffort` | 要因 | Should | iOS 18 以降 [要確認] |
| 運動 | 心肺機能（VO2max） | `vo2Max` | 長期の推移 | Could | 屋外のウォーキング・ランニングで推定される |
| 光 | 日光を浴びた時間 | `timeInDaylight` | 要因（量と時間帯） | Must | watchOS 10 以降の対応機種 [要確認] |
| 音 | 環境音の大きさ | `environmentalAudioExposure` | 要因（部屋の騒音の参考） | Could | ノイズ測定がオンの場合 |
| 音 | ヘッドフォンの音量 | `headphoneAudioExposure` | 要因（寝る前に動画・音楽を聞いていたか） | Could | AirPods などを使った場合 |
| 心 | 心の状態（気分・感情の記録） | `HKStateOfMind` | 要因・結果（翌日） | Should | 本人が記録した場合。iOS 18 以降 |
| 心 | マインドフルネス | `mindfulSession` | 要因（寝る前の呼吸セッションなど） | Could | — |
| 飲み物 | カフェイン・飲酒 | `dietaryCaffeine` / `numberOfAlcoholicBeverages` | 要因（量と時刻） | Should | 本人が記録した場合 |
| 周期 | 月経周期の記録 | `menstrualFlow` など | 基準線の補正（手首皮膚温・心拍が周期で変わるため） | Could | 記録している人が、使うことを選んだ場合だけ |

**使わないデータ**: 心電図、心房細動の履歴、不規則な心拍・高心拍・低心拍の通知、高血圧の通知、服薬の記録。病気の判定に関わるデータで、このツールは健康管理（ウェルネス）の範囲にとどめるため（要件定義書 6.3）。

### 2.2 部屋・手入力・天気
- 部屋: 室温・湿度・CO2・明るさ・在床・照明・窓とドア・カーテン・加湿空気清浄機（要件定義書 4.2）
- 手入力: 朝の体感（5段階）、入浴した時刻
- 天気: 外の気温・湿度・気圧

### 2.3 手入力を減らす工夫
- **カフェイン・飲酒**は、このアプリでワンタップ記録したものを **HealthKit にも書き込む**（ほかのアプリで記録した分も同じ場所から読める）。
- **気分**は Apple の「心の状態」（マインドフルネスアプリ）で記録していれば、それを読む。
- **朝の体感**（すっきり度）は気分とは別なので、このアプリで記録する。

### 2.4 サーバーに送る細かさ
バッテリーと通信量を抑えるため、必要な細かさだけ送る。

| データ | 送る細かさ | 理由 |
|---|---|---|
| 睡眠ステージ、睡眠中の心拍・HRV・呼吸数・血中酸素・手首皮膚温 | 測った値そのまま | 夜の詳細画面で、部屋の値と時間を合わせて重ねるため |
| 日中の心拍 | 1時間ごとの平均・最小・最大・測った回数 | 寝る前の心拍と、着けていた時間（装着の目安）がわかれば足りる |
| 歩数・カロリー・エクササイズ・スタンド・日光・環境音 | 1時間ごとの合計 | 「午前中の日光」「夕方以降の運動」のように時間帯で見るため |
| ワークアウト | 1回ごとの概要（種類・開始と終了の時刻・長さ・カロリー・平均心拍・運動強度） | — |
| 安静時心拍・歩行時の平均心拍・VO2max・心拍数の回復 | 1日の値 | Apple Watch が1日単位で出す値のため |
| 心の状態・マインドフルネス・カフェイン・飲酒 | 記録ごと | — |

## 3. 1日 = 1行の表

### 3.1 区切り方
- **夜**: 18時〜翌朝8時に始まった睡眠のうち、いちばん長いもの（時間帯は設定で変えられる）。日付は**起きた日**にする（例: 12/1 23:30〜12/2 7:00 の睡眠は「12/2 の夜」）。
- **日中**: 前の夜に起きた時刻から、その夜に布団に入った時刻まで。
- **寝る前**: 布団に入る前の2時間。
- **布団に入った時刻**: 人感センサー Pro の在床を優先し、なければ Apple Watch の「就床」を使う。
- 昼寝は夜とは別に記録し、「昼寝した日」として要因に使う。

### 3.2 列（例）
| 区分 | 列の例 |
|---|---|
| 睡眠（結果） | 実睡眠時間、睡眠効率、寝つきまでの時間、中途覚醒の回数と時間、深い睡眠・レム睡眠の時間、独自の睡眠スコア |
| 睡眠中の体（結果） | 平均心拍、最低心拍、HRV、呼吸数、血中酸素、手首皮膚温（それぞれ、いつもとの差も） |
| 翌朝・翌日（結果） | 朝の体感、翌日の安静時心拍、翌日の歩数・エクササイズ時間、翌日の気分 |
| 日中（要因） | 日光を浴びた時間（合計・午前中）、歩数、エクササイズ時間、スタンド時間、ワークアウト（合計時間・強さ・最後に終わった時刻）、昼寝、カフェイン（量・最後の時刻）、気分 |
| 寝る前（要因） | 平均心拍（いつもとの差）、照明の明るさ・色温度、入浴から就寝までの時間、飲酒、ヘッドフォンの使用、マインドフルネス、帰宅から就寝までの時間 |
| 部屋（要因） | 睡眠中の室温・湿度・CO2（平均・最高・1,000ppm を超えた時間）、睡眠中の明るさ、窓を開けて寝たか、加湿空気清浄機の運転 |
| その他 | 曜日、季節、外の気温・気圧、就寝時刻（いつもとの差）、**データの質**（Watch を着けていた時間、欠けたデータ） |

## 4. 個人の基準線（いつもの自分）

HRV・安静時心拍・呼吸数・手首皮膚温は、人によって普通の値が大きく違う。そのため、**ほかの人との比較ではなく、自分のいつもの値との差**で見る。

| 項目 | 決まり |
|---|---|
| 基準線 | 直近28日の中央値（真ん中の値）と、ふだんのばらつきの幅 |
| いつもとの差 | 「今日の値 − 基準線」を、ふだんの幅で割った値（±1 ならよくある範囲、±2 を超えたら珍しい） |
| 必要な日数 | 14日分たまるまでは基準線を作らない |
| HRV | 1回ごとのばらつきが大きいので、その夜の平均と、7日間の平均の両方で見る |

**「いつもと違う日」の扱い**: 安静時心拍・手首皮膚温・呼吸数のうち2つ以上が同時にいつもと大きく違う日は、体調がいつもと違う可能性がある。
- 画面には「いつもと違う値が出ています」とだけ表示する（病名や原因は言わない）。
- **条件別の比較からは外す**（風邪などの影響で、部屋の環境の効果が見えにくくなるため）。

## 5. 分析の段階

| 段階 | 内容 | 例 | 始められる時期 |
|---|---|---|---|
| **① 見える化** | 1晩の睡眠ステージ・心拍と、CO2・室温・明るさを同じ時間軸に重ねる。日ごとの推移を見る | CO2 が上がり始めた頃から眠りが浅い | 初日から |
| **② 条件別の比較** | 夜を条件で2つに分け、結果の平均を比べる。差と「差の範囲」を出す | 日光を30分以上浴びた日は、寝つきが平均9分早い傾向（差の範囲: 3〜15分、各14夜） | 約30夜から |
| **③ 自分に合う範囲** | 室温などを細かく区切って、結果がよい範囲を探す。通知の基準値に使う | 20〜22℃ の夜によく眠れている | 60〜90夜から |
| **④ 翌日への影響** | 睡眠のよかった夜とそうでない夜で、翌日の状態を比べる | よく眠れた翌日は、安静時心拍が2拍低く、歩数が1,500歩多い傾向 | 約30夜から |
| **⑤ 自分で試す実験** | 条件を決めた日と決めない日を交互に作り、効果を確かめる | 2週間、寝る前に5分換気する夜としない夜を交互に | ②で候補が見つかってから |

②〜④では、データが増えたら**複数の要因を同時に考える計算（重回帰）**を使う。たとえば「運動した日は外に出るので日光も多い」ように、要因どうしが重なっているときに、どちらが効いているかを分けるため。

## 6. 最初に調べる仮説

たくさんの組み合わせを調べると、偶然の差が混ざる。そのため、**調べる仮説と、見る結果を先に決めておく**。

| # | 要因 | 主に見る結果 | 使うデータ |
|---|---|---|---|
| H1 | 睡眠中の CO2（最高値・1,000ppm を超えた時間） | 深い睡眠、中途覚醒、朝の体感 | CO2センサー、Watch |
| H2 | 睡眠中の室温 | 深い睡眠、中途覚醒、手首皮膚温 | CO2センサー・ハブ3、Watch |
| H3 | 寝る前2時間の照明（明るさ・色温度） | 寝つきまでの時間 | シーリングライト、人感センサー Pro、Watch |
| H4 | 飲酒・カフェイン（量と時刻） | 睡眠中の HRV・心拍、寝つき | 手入力（HealthKit）、Watch |
| H5 | 運動（量・強さ・寝る何時間前に終えたか） | 深い睡眠、睡眠中の HRV | Watch のワークアウト |
| H6 | 日光を浴びた時間（合計・午前中） | 寝つき、就寝時刻 | Watch |
| H7 | 入浴から就寝までの時間 | 寝つき、深い睡眠 | 手入力、在床 |
| H8 | 就寝時刻のずれ（いつもとの差） | 睡眠効率、朝の体感 | 在床、Watch |
| H9 | 睡眠のよしあし（④） | 翌日の安静時心拍・HRV・歩数・気分 | Watch |

結果の指標は、たくさん見すぎないように次の4つを中心にする: **朝の体感、睡眠効率、深い睡眠の時間、睡眠中の HRV（いつもとの差）**。

## 7. 間違った結論を出さないための決まり

| 決まり | 内容 |
|---|---|
| 夜の数 | 比べるグループがそれぞれ **7夜以上** そろうまで結論を出さない（「データ不足」と表示） |
| 差の範囲 | 平均の差と一緒に、ばらつきを考えた「差の範囲」を出す（ブートストラップ法）。範囲が0をまたぐ場合は「差ははっきりしない」 |
| 再現 | データの前半と後半の**両方で同じ向きの差が出た**ものだけを「気づき」として表示する |
| 季節・曜日 | 季節（室温や CO2 が季節で大きく動くため）と、平日・休日に分けても同じ傾向かを確かめる |
| 時間の順番 | 「寝る前・日中の条件 → その夜の睡眠」「その夜の睡眠 → 翌日」の順でだけ比べる（眠れないから照明をつけた、などの逆向きを避ける） |
| 体調がいつもと違う日 | 4章の「いつもと違う日」は比較から外す |
| データの質 | Watch を着けていなかった夜、充電切れの夜、センサーが止まっていた夜は外す |
| 小さな差 | Apple Watch の睡眠ステージは推定なので、小さな差（例: 深い睡眠の数分の差）は「気づき」にしない [TBD: 基準] |

## 8. 表示と言葉づかいの決まり
- 「〜の傾向がある」と書き、「〜が原因」とは書かない。
- 夜の数と差の範囲を必ず一緒に表示する。
- 病気の判定や医学的な効果をうたわない（「睡眠時無呼吸」「不整脈」などの言葉を使わない）。
- 「いつもと違う日」は、値がいつもと違うことだけを伝える。続いて気になる場合は医療機関に相談するよう添える。

## 9. どこで計算するか

| 作業 | 場所 | 内容 |
|---|---|---|
| 毎朝の自動の計算 | サーバー（Cloudflare Workers） | 1日 = 1行の表、基準線、②〜④の比較、朝のレポートの文章 |
| 仮説探し | Mac（Python / Jupyter） | CSV を書き出して、自由にグラフや比較を試す。役に立った分析だけをアプリの機能にする |

| 時期 | できること |
