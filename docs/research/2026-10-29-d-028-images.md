4. **クリーブランド美術館**：「約3万件」は README の数です。README が古いかもしれません（今の件数は要確認）。
5. **国書 DB**：出典例の DOI（10.20730/200013710）が何を指すかは確かめていません（要確認）。
6. **絵巻**：「有名な絵巻は ColBase にない」は言い過ぎです。国立博物館が自分で持つ絵巻（地獄草紙・餓鬼草紙など）は入ります。寺社の持ち物で博物館に預けてある品（寄託品）は入りません (b)。

### 日本の法律では（すべて b か c）
- 平面の作品を忠実に撮った写真は、著作物ではないとされました（版画写真事件、東京地裁 平成10年11月30日。地裁の判断です）。
- 作品の持ち主の所有権では、複製を止められません（顔真卿事件、最高裁 昭和59年1月20日）。
- それでも、取った先のサイトの規約は守る前提で進めます (c)。政府標準利用規約の型は「本利用ルールに同意したものとみなします」と書いています（デジタル庁の写し、a）。
- 立体物（仏像・茶碗など）の写真は、撮った人の著作物になりえます (c)。立体物は、写真そのものの利用条件がはっきりした取り先から取ります。
- 保護期間
  - 1967年以前に亡くなった人の作品は、日本で保護が切れています。2018年の延長はさかのぼりません（手元の知識。要確認）。
  - 米国では、1930年までに出た作品は保護が切れています（手元の知識）。
- 保護が切れても、作者の人格を傷つけるような改変はしてはいけません（著作権法60条。c）。原画に色を付けて、元からそうだったように見せる、といった使い方は避けます。

### 古典の絵ならではの落とし穴
1. **寺社や私立の美術館の絵巻**は、寄託品なら ColBase に入りません。代わりに次のものを使います (c)。
   - 江戸時代の写し（模本）
   - 国立博物館が自分で持つ品
   - 海外の美術館が持つ断簡
2. **CC BY-SA と NC は使わない** (c)。本文についての SPEC R1 と同じ線を画像にも引く、という新しい決まりにします。
3. **YouTube の広告の決まり**（追加。c、要確認）
   - 地獄草紙・餓鬼草紙・九相図・無残絵・春画は、画像の規約で使えても、年齢制限や広告の制限につながるおそれがあります。
   - サムネイルには使いません。
4. **出典の出し方** (c)
   - 画像が出ている間は、画面の隅に短い出典を出します。説明欄にも一覧を書きます。
   - 手を加えた画像には「〜を加工して作成」と書きます。
   - 説明欄だけで足りるかは要確認です。
5. **誤った申し立てへの備え** (c)：取ったページの URL・権利の表示・確かめた日を残し、異議を申し立てるときに使います。
6. **宗教の品・肖像**：法律の制限ではありません。仏画を軽く扱わないようにします。著者カードには「近代日本人の肖像」を使います (b)。

### 足りない写真の数え方
- シカゴ美術館：API で is_public_domain に絞り、limit=0 で件数だけを取れます (a)。
- Met（isPublicDomain）・クリーブランド美術館（CC0 の項目）：要確認。

### 実装の案 (c)
- 画像ごとに台帳に残す項目：取ったページの URL、見た権利の表示、確かめた日、出典の文、手を加えたかどうか。今の ref_works と同じやり方です。
- SA・NC・権利の表示がないものは、自動で外します。
- SPEC では、資料画像カードは今のところ国会図書館のページ画像だけです。ColBase や Met を足すなら、先に SPEC と docs/decisions.md に書きます。

## 検証で足した点・確かめられなかったこと
- この検証では、規約のページ（colbase.nich.go.jp、kokusho.nijl.ac.jp、metmuseum.org など）が DNS で見つからず開けなかった。検索もこの回の上限（200回）に達して使えなかった。原文を確かめるには、これらのホストをセッションのネットワーク設定で許可するか、Mac のブラウザで読む必要がある。続きは次のメッセージで頼める
- YouTube の広告の決まりとサムネイルの決まり：地獄草紙・餓鬼草紙・九相図・無残絵（血みどろの浮世絵）・春画・裸体は、画像の規約では使えても、年齢制限や広告の制限、サムネイルの削除につながるおそれがある（推論、要確認）。サムネイルには使わない
- e国宝（同じ国立文化財機構）は私的利用だけと第三者が記録している。同じ作品でも、e国宝からは取らず、ColBase から取る
- ColBase に入る皇居三の丸尚蔵館の品（蒙古襲来絵詞・春日権現験記絵などの絵巻を含むかもしれない）に、ColBase の条件がそのまま当たるか（要確認）
- 日本美術の多い海外の館で、商用が自由でないもの：ボストン美術館・ハーバード美術館など（要確認）。まだ調べていない候補：ミネアポリス美術館、LACMA、ウォルターズ美術館、イェール大学の美術館（要確認）

- 足りない写真の数え方：シカゴ美術館は API の is_public_domain と limit=0 で数えられる（a）。Met の isPublicDomain、クリーブランドの CC0 の項目、スミソニアンの API キー、ジャパンサーチの Web API で ColBase・国会図書館の資料を数えられるかは要確認
