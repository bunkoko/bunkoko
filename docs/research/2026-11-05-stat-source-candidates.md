## はじめに：結論

- **新しく使えそうなもの**は、役所の統計を中心に約25件あります。役所の統計は、ほとんどが「出典を書けば、収益化した動画でも使える」規約です（公共データ利用規約 PDL1.0 か、政府標準利用規約）。
- **ただし今回は、役所のサイト（go.jp）をこの環境から開けませんでした。** 検索結果の抜粋だけで調べています。数字・公表日・URL・規約の文は、全部、人が元のページを開いて確かめてから DB に入れてください。「要確認」「抜粋」と付いた数字は、そのまま語りに使わないでください。
- **民間の調査**は、引用の決まりが見つからない・はっきりしないものが多く、ほとんどは「問い合わせてから」です。
- **すでに使っている資料**で気をつけること：日本財団は今の読みでは使えません。マイナビと学情は、確かめるまで保留です（9章）。
- **「増え続けています」**と言えそうなものは少なく、国勢調査の一人暮らしの割合と、年休の取得率くらいです（6章）。
- **「〇〇大の研究では」**の候補はハーバード大などの研究、オックスフォード大、大阪商業大の3つです（7章）。ただし今の台本の検査では、研究の話は止まります。

## 共通の条件と注意

**国の統計の共通の条件**
1. 出典を書く。例：「出典：厚生労働省『雇用動向調査』（令和7年）、そのページのURL」
2. 丸めたり（33.8% → 約3割）、差を出したりしたら、概要欄に「〇〇をもとに作成」と書く
3. 国が作った、国がすすめている、という見え方にしない
4. 表やグラフの画像は写さず、数字だけを使う（チャンネルの決まり）
5. 各省の「利用規約」「著作権について」のページを、人が一度開いて確かめる（今回は開けていません）

**民間の調査の共通の条件**（D-035）
社名・調査名・調査の時期を書く／改変しない／数字だけを使う／元のページを出典にする／語りでは「民間の調査」と分かるように言う

**語りでの共通の注意**
- 「誰のうちの割合か」（分母）を言う。例：「転職した人のうち」
- いくつ選んでもよい問いは「いくつ選んでもよい問いで」と添える
- ネットの調査は「調査に答えた人のうち」と言う
- 国の順位には国ごとの答え方のくせが入るので、発行元がそう書いている範囲だけで言う

## 6. 「増え続けています」について

ご指示どおり、統計から本当にそう読み取れるときだけ使います。人が元の推移表で毎回増えていることを確かめ、stats.csv の trend・trend_note の欄に書いた統計の隣の段落でだけ、語りで言えます（今の台本の検査がそうなっています）。

**言えそうなもの**（元の表で確かめてから）
- 国勢調査の、一人暮らしの世帯の割合：1990年から2020年まで、毎回上がっている（厚生労働白書の図の抜粋）。2025年調査でも上がっていれば言えます。65歳以上の一人暮らしも同じです。
- 就労条件総合調査の、年休の取得率：最新の値が昭和59年以降でいちばん高い。最近の毎年の値が続けて上がっていれば言えます。

**言えないもの**（言い換えの例）
- 新規学卒の3年以内の離職率：令和4年3月卒は下がった →「3割ほどの状態が長く続いている」
- 職場でパワハラを受けた人：31.4%から19.3%に下がった
- 転職者の数と、転職などを望む人の数：途中で減った年がある
- いじめの件数：令和2年度に一度減った →「学校が把握した件数は過去最多」
- 国民生活世論調査：2021年に調べ方が変わった
- 出生動向基本調査の「いずれ結婚するつもり」：上がった回がある →「長い目で見て下がってきた」「前回より下がった」
- 本を読まない人：横ばいの時期がある →「前回より増えた」まで
- 社会生活基本調査の令和3年：コロナの時期の特別な年
- 学情（答えたのは数百人）、明治安田（2回だけ）、Gallup（年に1〜2ポイントの動き）、World Happiness Report（3年分の平均）
- 白書の先の推計：「見込み」としてだけ言う

## 7. 研究（「〇〇大の研究では」）に使えそうなもの

ご指示（研究は脇役でよい。主張を補強するためなら1回に何度でも。「〇〇大の研究では」も可。D-034）に合う候補です。
- **Global Flourishing Study**：「ハーバード大などの研究では」と言える。論文の利用条件を要確認
- **World Happiness Report**：「オックスフォード大学などがまとめる世界幸福度報告では」と言える。Gallup の条件がかかる
- **JGSS**：「大阪商業大学の調査では」と言える。引用の条件を要確認
- **パーソル総合研究所の幸せの調査**：慶應の前野研究室と一緒に行ったと確かめられれば「慶應義塾大学との共同の調査では」と言える

**注意**：今の台本の検査では、研究の話は止まります。研究の一文を入れる台帳（M8d）ができてから使えるようになります。大学名や論文の年は、その台帳から記号で差し込みます。有料の論文は、書誌と、人が自分の言葉で書いた1文だけを持ちます（D-034）。

## 8. 使わないもの（理由）

| 発行元・調査名 | 理由 |
|---|---|
| 労働政策研究・研修機構（JILPT） | 無断の複写・転載を禁止していて、許諾が要る。問い合わせのフォームは営業目的を受け付けない（抜粋）。白書の図で、元が JILPT のものも使わない |
| NHK放送文化研究所「日本人の意識」調査、ISSP の日本の結果 | NHK のページはふつう「許可なく転載禁止」（文研のページでは未確認）。ISSP の部分は D-035 で使わないと決めている。許可が要らないと文書で分かったときだけ見直す |
| 日本生産性本部「新入社員『働くことの意識』調査」 | 転載や複製に許可が要り、統計は事前の連絡を求めている。2019年度で終わったとみられる |
| 日本財団「18歳意識調査」（すでに使っている） | 英語のサイトの規約では、個人の利用以外は許可が要る。日本語のサイトに別の決まりがあれば見直す |
| 博報堂生活総合研究所「生活定点」 | 商用の利用には事前の承諾が要る。AI に入れることも禁止 |
| World Values Survey（世界価値観調査） | 非営利の利用だけ |
| ISSP（GESIS が配布） | 商用は禁止で、学術用だけ |
| 世界経済フォーラム「ジェンダー・ギャップ報告」 | 非営利・改変なしの条件か、「すべての権利を持つ」という表示 |
| 電通「ウェルネス1万人調査」 | 問いの多くが健康（医療）で、幸福に使える問いが少ない |
| ユニセフの子どもの幸福度ランキング | 若者の自殺率が入っている（除外のテーマ） |
| World Happiness Report の Web の図や地図 | 非営利だけ（CC BY-NC-SA） |
| OECD や World Happiness Report の中の、Gallup のデータから来た数字 | Gallup に確かめるまで使わない |

**調査の中で使わない問い**（除外のテーマ）
- 雇用動向調査の「死亡・傷病」で辞めた人
- ハラスメント調査の、心や体への影響
- 文科省の調査の、自殺と重大事態
- 過労死等防止対策白書の、病気と自殺の件数
- 国民生活世論調査の「健康」
- 出生動向基本調査の、結婚のお金
- 高齢者の国際比較調査の、暮らし向きと健康
- ソニー生命のお金の問い、ブライダル総研の費用、Ipsos の経済的な状況
- World Happiness Report の健康寿命
- Global Flourishing Study の、健康とお金の分野
