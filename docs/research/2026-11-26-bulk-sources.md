# 統計と論文をまとめて取れるところ（2026-11-26 調べ）

利用者の問い：「論文など統計を大量に入手できるところはない？圧倒的に不足している」。
今の統計の台帳（config/stats.csv）は 53 行で、テーマごとに 2〜4 行。研究の台帳（config/findings.csv）は 22 行。

- 調べ方：調べ役が公式のページを開いて読み、別の見直し役が同じページを開き直して1つずつ確かめた（2026-11-26）。登録・フォームの送信・個人の情報の送信はしていない。
- このクラウドの環境から開けなかったページがある（下の「開けなかったところ」）。そこは検索の抜き出しだけで、**未確認**と書いた。Mac の koten（net.py）はふつうにネットにつながるので、取り込みそのものには関わらない。
- どれを取り込むかは、まだ決めていない（台本の作りの見直しと一緒に決める）。

## 1. 日本の統計

### e-Stat の API（中心になる）

- 取れるもの：e-Stat の「データベース」に載っている表（FAQ「データベースで表示されているものが、API機能で取得できます」）。2026-11-26 で 294 調査・227,224 件。
- 形：REST（api.e-stat.go.jp/rest/3.0/app/…）。XML・JSON・CSV。1回に 10 万件まで（続きは NEXT_KEY）。
- 登録：**利用者本人の e-Stat の登録（メールアドレス）と、アプリケーション ID（appId）が要る**（API 規約 第2・3条。1人3つまで。人に貸さない）。
- 回数の制限：FAQ「現在のところ、ございません」。ただし「短時間における大量のアクセス」は禁止（第8条）、負荷で制限がありうる（第5条）。net.py のレート制限とキャッシュを通す。
- 商用：使える。FAQ「API機能で提供しているデータは、政府統計の総合窓口(e-Stat)の利用規約に準じているため、商用利用が可能です。」
- データの規約（e-Stat 利用規約。政府標準利用規約 第2.0版に準拠、CC BY 4.0 と互換）：
  - 「商用利用も可能です」「数値データ、簡単な表・グラフ等は著作権の対象ではありません」。
  - 出典を書く（例「出典：「○○調査結果」（A省）」）。グラフにするなど加工したら「「○○調査結果」（A省）を加工して作成」と書く。国が作ったように見せない。
- API を使ったサービスのクレジット（クレジット表示のページ）：「このサービスは、政府統計総合窓口(e-Stat)のAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。」。動画が「サービス」に当たるかは書いていない。説明欄に入れておくのが安全（利用者が決める）。
- 出典に要る情報は、統計表の情報（政府統計名・作成機関・表題と表番号・調査年月・公開日・最終更新日）に入っている。ただし表の URL の項目は無い。サイトは表を `https://www.e-stat.go.jp/dbview?sid=<統計表ID>` で開くが、変わらないリンクだという記述は無い。統計表 ID は基準の改定で変わることがある（2026-07-10 の消費者物価指数のお知らせ）。取った日と最終更新日を一緒に残す。
- **注意：データベースが古いままの調査が多い。** 新しい年はファイル（Excel・CSV）にしか無い。
  - 雇用動向調査：DB は 2019 年か 2021 年まで、ファイルは 2025 年まで。
  - 就労条件総合調査：DB は 2020 年まで、ファイルは 2025 年まで。
  - 毎月勤労統計の長期の表：DB は 2015 年まで。
  - 国民健康・栄養調査：DB は 2019 年まで、ファイルは 2024 年まで。
  - 労働安全衛生調査（強いストレスの割合など）・出生動向基本調査・人々のつながりに関する基礎調査（孤独）：DB に無く、ファイルだけ。
  - ファイルの一覧とダウンロードの URL は、API のデータカタログ情報取得で取れる。ファイルの直接のダウンロード（file-download?statInfId=…&fileKind=0）は登録なしで取れた。
- 長い時系列の例（「昔と比べる」に使える）：
  - 人口動態総覧：1899〜2024 年。
  - 労働力調査（年齢階級別の労働力人口比率・就業率・完全失業率）：1953〜2025 年。
  - 国民生活基礎調査の生活意識（苦しい・普通・ゆとり）：1986〜2024 年（2020 年は調査なし）。
  - 社会生活基本調査（生活時間）：1986〜2021 年の 8 回。1976 年からの時系列表はファイル。
  - 国勢調査：DB 6,237 表（単身の世帯・未婚の割合など）。
- コロナの年の抜け：国民生活基礎調査は令和2年が無い。国民健康・栄養調査は 2020・2021 年が無い。グラフでは抜けた年を空ける。

## 2. 国際機関の統計

**どれも検索の抜き出しだけ**（www.oecd.org・ilostat.ilo.org・www.worldbank.org などを開けなかった）。使う前に、指標ごとに規約のページを開いて確かめる。

- 使えそう（出典を書けば商用も可とされる）：
  - OECD Data Explorer（労働時間・How's Life? の幸福度、孤独は 2024 年から）。API は1時間に 60 回まで。幸福度の一部は Gallup World Poll が元で、別の制限があるかもしれない。
  - ILOSTAT（週 49 時間以上の割合など）。
  - World Bank WDI（1960 年からの系列が多い）。一部の系列は CC BY-NC。
  - 国連の世界人口推計（CC BY 3.0 IGO。1950〜2100 年）・UNdata。
- 使わない：World Values Survey・ISSP・Gallup（非商用・学術だけ）、European Social Survey（CC BY-NC-SA）、Eurofound の EWCS の個票（商用は許可が要る）、WHO の刊行物（CC BY-NC-SA）。World Happiness Report はデータの規約が見つからない。WHO の data.who.int は CC BY 4.0 だが、別の「公衆衛生の目的」の条件があり、確かめるまで使わない。

## 3. 論文

- 探す：**OpenAlex**（約 2.5 億件の書誌。データは CC0）。
  - ライセンスで絞れる（`best_oa_location.license:cc-by`。CC0 は `public-domain` と書き、ほかのパブリックドメインと一緒になっている）。
  - 研究の型（メタ分析・系統的レビュー・ランダム化比較試験など）の印もあるが、機械で付けた印で、付いているのは約2割。無いことを「RCT ではない」と扱わない。
  - 要旨は「due to legal constraints」で単語の位置の表でしか配らない。論文が CC BY・CC0 と確かめるまで要旨を取らない（D-034）。
  - キーの要否は資料で食い違う（2026年2月「すべての要求にキーが要る」と、今のヘルプ「キーなしは1日 $0.10」）。キーを作るには登録が要る（利用者が決める）。キー不要のスナップショット（約 675 GB）を HDD に落とす方法もある。
- 本文：**PMC の Open Access（AWS の S3、pmc-oa-opendata）**。登録・料金なし。2026 年 8 月に古い FTP と OA Web Service は無くなった。
  - 論文ごとの JSON に license_code（"CC BY"・"CC BY-NC-ND" など）があるが、版の番号が無く、本文の利用条件の文と食い違う例があった（米国政府の雑誌で license_code は "CC BY"、文はパブリックドメイン）。台帳に入れる前に、XML の `<license>` の URL と文の両方で確かめる。
- ライセンスと取り下げ：**Crossref**（メールアドレスなしで使える。一覧は毎秒1回）。論文ごとのライセンスの URL と、取り下げ・訂正（updated-by）が分かる。
- 雑誌の名前では決められない（Crossref で 2025 年以降を数えた割合）：
  - CC BY-NC-ND の割合：Scientific Reports 70.9%、BMC Psychology 76.7%、BMC Public Health 69.9%。
  - Frontiers：100% CC BY 4.0。MDPI：99.95% CC BY。PLOS：CC BY 97.4%・CC0 2.6%。
- 日本の論文：
  - J-STAGE の WebAPI は、営利で使うなら有償・無償に関わらず JST への申請が要り、24 時間を超えて保存できない。CiNii の API は学術研究・非営利だけ。
  - Crossref に載る日本の心理・産業衛生の雑誌は、ライセンスの登録が 0%。
  - 日本の論文は、書誌を Crossref・OpenAlex から取り、本文は人が読んで自分の言葉で一文を書く（D-034 の有料の論文と同じ扱い）。
- 回数の目安：E-utilities（PubMed・PMC の検索）はキーなしで毎秒3回。tool と email は「お願い」で必須ではない（私たちは送らない）。大きな処理は米国東部時間の夜（日本時間の平日 11:00〜19:00 ごろ）か週末に、と求めている。
- CC BY の論文でも、図や写真に他人の権利のものが入ることがある。図を画面に出すときは図ごとに確かめる。
