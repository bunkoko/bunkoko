# 説明欄の書き方と、調査・研究の取り先（2026-11-05）

オーナーが「うまく書けている」と貼った YouTube の説明欄（静かな退職の回。別のチャンネル）を手本に、書き方と、データの取り先を調べた。調べ役4人（説明欄の組み立てと YouTube の決まり・調査と統計の取り先・論文の扱い・今のコードへのはめ込み）が調べ、1人が案にまとめ、3人（権利・正確さ・コードと作業量）が案の問題を洗い出した。

**注意**：この環境からは、YouTube のヘルプ・厚生労働省・内閣府・e-Stat・Gallup・マイナビ・OpenAlex・Crossref のページを開けなかった。決まりや数字は、検索結果の抜粋で見ただけなので「要確認」とする。オーナーがブラウザで確かめるか、この環境から開けるようにしてから確定させる。

## 1. 手本の説明欄の組み立て

6つのかたまりでできている（全角で約940字）。

| # | かたまり | 中身 |
|---|---|---|
| 1 | つかみ（1行目） | 見ている人の様子を書いた短い2文と、問いかけ。「会議で黙るようになった。定時で帰るようになった。そんなあなたは、周りから『やる気がない』と見られていませんか。」 |
| 2 | 約束（2行目） | 「この動画では、［調査と研究、実験］をもとに、［誰が］『［検索語］』を選ぶ理由を、『［覚えやすい見立て］』というしくみで解き明かします。」 |
| 3 | ▼目次 | 0:00 はじめに、第1〜3章（主張か問いの題）、ふり返り、今日からできること、最後に |
| 4 | ▼この動画で使った研究・データ | 調査2つ（発行元・調査名・何年の結果か・発表日）と論文5本（著者 (年). 雑誌名, 巻(号).） |
| 5 | 注意書き | 「すべての職場に当てはまるものではありません」「天秤や箱は、しくみを説明するためのイメージです」 |
| 6 | 問いかけとハッシュタグ | 見立ての言葉を使った体験の問いかけ（「よければ」で柔らかく）と、ハッシュタグ3つ（話題・分野・見る人） |

- 説明欄に、調査の数値（割合や人数）は書いていない。数値は動画の中だけで出している。
- 出典の URL・DOI は載っていない。このチャンネルは R7 で出典・URL・DOI を載せる決まりなので、ここは手本に合わせない。

### データの取り先（4種類）

| 種類 | 手本の例 | 性質 |
|---|---|---|
| 海外の調査会社の報告 | Gallup「State of the Global Workplace」 | 会社の独自の調査と指標（engagement）。査読は無い |
| 日本の会社の調査 | マイナビ「正社員の静かな退職に関する調査2026年（2025年実績）」 | ネット調査（n=3,000）。発表文（プレスリリース） |
| 理論の論文 | Akerlof (1982)「贈与交換」 | 経済学の理論 |
| 実験・アンケート・メタ分析の論文 | Kube ほか (2013) の野外実験、Bolino ほか (2010・2015)、Zhao ほか (2007) のメタ分析 | 査読のある有料の雑誌。どれも CC BY ではない |

- 5本の論文は1982〜2015年のもので、どれも「静かな退職」そのものを調べた研究ではない。「おまけの天秤」は、作り手がいくつかの研究を組み合わせた見立て。組み合わせること自体は正当だが、「研究によると静かな退職は…」とは言えない。
- 贈与交換の研究は、のちの実験で「良い待遇へのお返し」が弱い・続かないという結果もある（Gneezy & List 2006 など）。手本はそこに触れていない。研究を使うときは、こうした限界も語る必要がある。

### 見つかった問題

1. **台本の検査が、作り話の研究や数字を止められない**（いちばん大きい）。調べ役が今のコードで試したところ、次の6つの文が、どれも G1 を通った。
   - 「ある調査では、日本の会社員の7割が…」
   - 「研究によると…分かっています」
   - 「3人に1人が…」
   - 「約半数の人が…と言われています」
   - 「心理学の実験で、科学的に証明されています」
   - 「ハーバード大学の研究では…」

   いまは G3（AI の判定役）だけが頼りで、古典の章の判定役は一節に忠実かしか見ない。数字や研究の話を増やす前に、ここを直す必要がある。「増え続けています」「多くの若者が」「最新の調査では」のような、数字の無い言い方も同じ。
2. **stats.csv の出典が元の資料でない**。6件のうち4件が、新聞（労働新聞 rodo.co.jp）3件と転載のページ1件。元の資料（厚生労働省・日本財団のページ）に差し替える必要がある。
3. **統計の書き方で意味が変わる**。39.5%（仕事の量）は「強い不安・ストレスがある人のうち」の割合だが、今のラベルだと語りで「働く人の4割」と聞こえる。55,614件（いじめ・嫌がらせ）は相談の件数で、「14年連続最多」は件数が増え続けたという意味ではない（相談の内容でいちばん多いという意味）。
4. **「孤独は20代が高い」**（SPEC §9）は、令和7年の調査では30〜50代に変わっているかもしれない（要確認）。
5. **民間の調査の2件（日本財団・学情）**が、利用規約を確かめないまま企画に出せる状態にある。

## 3. 取り先ごとの決まり（調べた範囲。要確認）

### 国の統計（いちばん使いやすい）

- 厚生労働省・内閣府・総務省統計局・e-Stat は、公共データ利用規約（第1.0版。CC BY 4.0 と両立）か政府標準利用規約（第2.0版）。**商用で使ってよく、出典を書けばよい**。数値や簡単な表は、そもそも規約の対象外（自由に使える）。
- 自分で作ったグラフや、計算し直した数字には「〇〇をもとに当チャンネルが作成（加工）」と書く。国が作ったように見せない。
- 白書の図のうち、民間の調査から取ったものは、白書ではなく元の調査を出典にする。
- e-Stat の API は、いまは使わない（stats.csv は年1回、人が更新する。労働安全衛生調査の表は Excel のファイルで、API の表になっていないようだ）。

### 会社・海外の調査（条件つき）

| 発行元 | 調べた決まり（抜粋） | 収益化した YouTube で使えるか |
|---|---|---|
| Gallup | 本・ニュース・ブログでの「文脈の中の引用」は許可なしで可。発表日を文に入れる。表やグラフの複製は許可が要る。ページへのリンクが要る。Q12 の質問文は複製禁止 | YouTube は書かれていない。メールで確かめる |
| マイナビ | 引用には社名・調査名・調査時期を書く。改変・販売・出所なしの転載は禁止 | サイトの方針が「非営利だけ」かもしれない。確かめる |
| リクルートワークス研究所 | 決まった出典の書き方を守れば転載可。機関誌 Works は不可 | 商用は書かれていない。問い合わせる |
| パーソル総合研究所 | 著作権法の引用の範囲で、出所を書けば引用・転載可 | おおむね可（要確認） |
| 日本生産性本部 | 出所の明記。転載・複製は許可、統計は事前の連絡 | 許可が要る |
| 日本財団 | 英語の利用条件は個人の利用だけ | 確かめる |
| OECD | 2024年7月からのものは CC BY 4.0 | 可（データごとに第三者の指標でないかを見る） |
| World Values Survey・ISSP | 非営利・学術の利用だけ | 使わない |

- ネット調査やサイトの訪問者に聞いた調査（マイナビ・学情・日本財団のネット調査）は、「答えた人のうち」の割合で、世代や国全体の数字ではない。語りでも「民間の調査では」「調査に答えた〇〇のうち」と言う。
- Gallup の「熱意をもって働く人」は Gallup 独自の指標。国どうしの順位（「日本は世界最低」）は、答え方のくせの差も含むので、発行元がそう書いていない限り言わない。

### 論文

- **見つける**：OpenAlex（書誌は CC0。2026年2月から API キーが要る）と Crossref（書誌は事実なので自由。API は登録不要）。Semantic Scholar の API は商用に制限があるので使わない。J-STAGE・CiNii の API は、商用で使う前に問い合わせる（ブラウザで人が探すのはかまわない）。
- **本文と要旨**：
  - CC BY・CC0 の論文（PMC の公開分など）は、本文を HDD に置き、AI に渡してよい（SPEC §6 のとおり）。訳して出すときは「改変あり（翻訳）」と書く。
  - それ以外（有料の論文）は、**要旨も著作物**。OpenAlex の要旨（単語の位置の索引）も元の文に戻せるので、同じ扱い。今の本（S4）と同じく、保存せず、クラウドの AI（Claude Code・翻訳サービスを含む）に渡さない。人が読んで、自分の言葉で書いた1文だけを使う。
  - 書誌を取るときも、OpenAlex・Crossref の返事に要旨が入っている。net.py は返事をそのまま raw/ に保存するので、書誌だけを残す取り方を足す必要がある。
- **正確さ**：
  - 取り下げ（撤回）・訂正は Crossref（Retraction Watch のデータを含む）で確かめる。論文の記録の updated-by を見る。
  - 取り下げられていなくても、大きな追試で再現しなかった研究がある（自我消耗・パワーポーズなど。このチャンネルの題材と重なる）。追試の結果（再現した・まちまち・再現しない・まだ）を記録し、再現しないものは使わない。
  - 発表文や要旨は、結果を大きく言いがち。人が本文の結果の節で確かめたものだけを使う。
  - 理論は「考え方」、相関は「関係がある」（原因と言わない）と言う。

## 4. 説明欄のひな形（案）

`{{…}}` は DB・設定から機械で入れる所、〈…〉は検査を通った台本の文から入れる所。

```
〈冒頭のナレーションの最初の1〜2文。悩みの場面と「〜していませんか」〉
この動画では、{{主役の著者}}『{{主役の作品}}』などの古典の一節を手がかりに、「{{悩み}}」という悩みを、「〈見立て〉」という見方で考えます。{{悩みの背景として、国の統計の数字も紹介します。（使ったときだけ）}}

▼目次
0:00 はじめに
{{m:ss}} 第1章 〈章の題〉
{{m:ss}} 第2章 〈章の題〉
{{m:ss}} 第3章 〈章の題〉
{{m:ss}} ふり返りと、今日からできること
{{m:ss}} 最後に

▼この動画で読んだ古典
・{{著者}}『{{作品}}』「{{章}}」（底本：{{底本}}）{{URL}}　{{ライセンス・試訳・元の訳の注記}}

▼この動画で使った調査・データ
・{{発行元}}「{{調査名}}」（{{調査の時期}}）{{発表日}}発表　{{元の資料の URL}}

▼背景と昔の資料の出典
・{{事実の確認元}}　{{URL}}
・{{資料の表記}}（{{コマ}}）{{国会図書館の URL}}

▼参考にした本（広告）
Amazonのアソシエイトとして、{{チャンネル名}}は適格販売により収入を得ています。
・{{書名}}（{{出版社}}）{{リンク}}

音声：VOICEVOX:{{キャラクター}}　BGM：{{BGM のクレジット}}　画像：{{画像のクレジット}}

{{注意書き：使ったものに応じて、決まった文から選ぶ}}

〈問いかけ〉よければコメント欄で教えてください。

#{{テーマのタグ}} #{{見る人のタグ}} #古典
```

- 2行目の言葉は、その回で実際に使った資料の種類からプログラムが決める（国の統計→「国の統計」、公的機関→「公的機関の調査」、国際機関→「国際機関のデータ」、民間→「民間の調査」、まざる→「調査のデータ」）。見立てを、調査や研究の結論のように書かない。
- 注意書き（決まった文の案。AI には書かせない）：
  - いつも：古典の読み方はひとつではありません。この動画の読み方は、そのひとつです。
  - 見立てを出したとき：「〈見立て〉」は当チャンネルの読み方で、古典の作者や調査の結論ではありません。
  - 調査・研究を使ったとき：調査や研究は、ある時期・ある人たちを調べた結果で、すべての人に当てはまるものではありません。
  - 統計のグラフを出したとき：グラフは、上の資料の数値をもとに当チャンネルが作りました。
  - 昔の辞書・注釈を使ったとき：昔の辞書や注釈は、その時代の説明として紹介しています。
  - 原文から自分で訳したとき（R5）：該当の行に「（試訳）」を付ける。
- 問いかけは、考えや日々の経験だけを聞く。健康・お金の判断・法律のもめごと・勤め先や学校の名前は聞かない。除外カテゴリの言葉（blocked_keywords.yaml）の検査も通す。
- 字数の上限（5,000。全角の数え方）は要確認。出典（R7）の行は削らない。長すぎるときは参考にした本から減らす。

### 見本（上の2行だけ）

> 同期が先に昇進した。「おめでとう」と言ったあと、ひとりになると胸がざわつく。そんな自分を、心が狭いと責めていませんか。
> この動画では、三木清『人生論ノート』などの古典の一節を手がかりに、「同期の昇進を素直に喜べない」という悩みを、「借りものの物差し」という見方で考えます。

## 5. オーナーが決めること（推奨つき）

| ID | 決めること | 推奨 |
|---|---|---|
| 研究の役割 | 手本は研究が話の中心。このチャンネルでは研究をどこまで使うか | **脇役**。1回に1件まで、悩みを見る章（形式A の研究の章）だけ。古典が柱 |
| 有料の論文 | CC BY でない論文を使ってよいか（SPEC §2 と §6 が食い違っている） | **条件つきで使う**。書誌と、人が本文の結果を読んで書いた1文だけを持つ。要旨も本文も保存せず、クラウドの AI に渡さない |
| 民間の調査 | マイナビ・Gallup などを使ってよいか | **当面は国の統計・公的機関・OECD だけ**。民間は、メールで商用の可否を確かめてから1社ずつ足す |
| 統計の出典 | 元の資料（役所・会社自身のページ）だけにするか | **元の資料だけ**。新聞・転載・まとめサイトは読み込みで弾く |
| 検査の強化 | 作り話の研究・数字を止める検査を、今のうちに足すか | **今すぐ足す**（M5 のコードの直し） |
| 説明欄の形（M6 で） | 1行目は冒頭のナレーションから、2行目は決まった型と見立て、注意書き・問いかけ・ハッシュタグ3つを付けるか | 上のひな形のとおり。M6 を始めるときに決める（変えたい所があれば言ってもらう） |

## 6. 進め方（案）

- **今**：検査を強くする（研究・調査・数字の言い方は、統計の差し込みと並んだときだけ。「証明」「最新の調査」などは使わせない。問いかけも検査する）。stats.csv のラベルを「誰のうちの割合か」が分かる書き方に直す。民間の2件は、規約を確かめるまで企画に出さない。オーナーは、元の資料で数字・発表日を確かめて出典を差し替える。
- **M6**：説明欄を組み立てる仕組み。調査の台帳（発行元・発表日・対象・人数・規約を確かめた日）と、`{{cite:}}`。最後の検査（出典の行がその回で使ったものと合うか、ライセンスの注記、字数）。
- **M8d（任意。M6 のあと）**：研究の1文（findings）を足す。論文の書誌の取り方（要旨を残さない）、取り下げ・追試の確かめ、判定役の「研究の文」の型。
