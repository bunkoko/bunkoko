## 先に結論

   ただし、SBI の別のガイド（S 株の画面の操作案内）は「10:30〜**13:30**」と書いていて、**14:00 と 13:30 の食い違い**がある。14:00 の版が**表示に 15:30 と書く**ので、2024-11-05 の引けの延長の後の更新版と読める（13:30 は 15:00 引けの時代の旧版と思われる＝推測）。**利用者が見るリンク先（S 株取引ルール）で確かめる**。
2. **S 株の売り買いの差（スプレッド）の数字は、公式でも解説でも見つからなかった。** 解説は「**S 株の売却時にスプレッド（実質的な手数料）が発生する**」と書く。買いの差は不明。
3. **画面の「市場の選択（SOR・東証・PTS）」が S 株の約定の変更のためか、検索では分からなかった。** S 株の約定方式が 2024〜2026 年に変わったことを示す告知は見つからなかった（最良執行方針の改定は 2025-12-13 と 2026-06-27 にあるが、S 株には触れていない）。S 株は従来「価格・期間を指定できない（成行のみ）」と解説されるので、**画面にある『価格・期間』の欄がある理由も含め、リンク先の最新の規則で確認する**必要がある。
4. **1 株単位の注文を API で出せる手段は、確認できなかった。** 立花証券 e 支店（単元未満株・規約・審査は見つからず）、moomoo の OpenAPI（日本株の対象に入っているが、日本の口座で実注文できるか・ひと株を注文できるかは見つからず）、そのほかの国内証券も見つからなかった。
   **SBI のサイトやアプリを、プログラムで画面操作して注文することを、禁じているか許しているかは、規約の本文に届かず確認できなかった。** 禁止の可能性が高いので、やらない（下の 2-3）。

## 1. SBI の S 株の今の決まり

### 1-1. 受付の時間ごとの約定（SBI の「お取引注意事項」の S 株の表。公式の抜粋）

| 注文の時間（営業日） | 約定のタイミングと値段 |
|---|---|
| 0:00〜7:00 | **当日の前場の始値**（表示 9:00） |
| 7:00〜10:30 | **当日の後場の始値**（表示 12:30） |
| **10:30〜14:00** | **当日の後場の引け（終値）**（表示 **15:30**） |
| 14:00〜24:00 | **翌営業日の前場の始値**（表示 翌 9:00） |
| 非営業日の注文 | その後の最初の営業日の 7:00 までの注文として扱う |

- **食い違い**: SBI の S 株の画面操作のガイドは、**7:00 前 → 前場始値、7:00〜10:30 → 後場始値、10:30〜13:30 → 後場引け、13:30 以降 → 翌営業日の前場始値**と書く（地方市場は 10:30 以降の注文を受け付けず売却のみ、とも）。
  14:00 の版は表示に「15:30」とあるので **2024-11-05 以降の更新版**、13:30 の版は旧版と読める（推測）。**どちらが今の運用かは、利用者のリンク先で確認が必要**。13 時台の注文は、**どちらの版でも 13:30 までなら引けで約定**する。13:30〜14:00 の注文は、新版なら引け、旧版なら翌営業日の前場始値で、**注意が要る**。
- **前場で約定しなかった注文は後場の始値に回り、それでも約定しなければ失効**する。**大引けがストップ配分になった場合、単元未満株への配分はなく約定しない**（公式の注意事項）。
- 「**当日中**」の成行（利用者の画面の期間）は、上の表のとおり**注文を出した時刻で約定の時刻と値段が決まる**。取引時間中にすぐ約定する形は、この表には**ない**（検索で見つからなかった）。

### 1-2. 画面の「SOR・東証・PTS」について

- SBI の通常の現物の注文画面には、市場の欄（当社優先市場／SOR、東証、名証、福証、札証、PTS）があり、**SOR の注文では逆指値や執行条件（寄成・引成など）が使えない**。これは**通常の注文画面**の説明（公式のガイド）。
- **S 株の画面に同じ市場の欄がある理由は、検索では見つからなかった**。S 株の取引ルールのリンクの題名が「**基準となる市場及び取引時間等**」であることから、**S 株の約定の値段の『基準になる市場』が決まっていて、その市場を画面で選ぶ形になった**可能性がある（**推測。裏づけなし**）。リンク先で、(a) 基準の市場に東証・SOR・PTS の違いが約定の値段にどう影響するか、(b) 引け（15:30）の値段が東証の板寄せの終値か、を読む。
- 画面に **「価格・成行」「執行条件なし」「期間・当日中」**の欄があるが、解説は「S 株は価格・期間を指定できない」と書く。**成行のままにして、ほかを触らない**のが安全（推測）。

### 1-3. 手数料・売り買いの差

- 手数料: **ゼロ革命の対象**（S 株を含む国内株の現物・信用）。条件は報告書などの電子交付、インターネットコース（公式の抜粋）。
- **スプレッド**: 「S 株の**売却時**にスプレッド（実質的な手数料）が発生する」（解説）。**幅の数字は公式・解説とも見つからなかった**。「買いは実質かからない」との表現もあるが、**買いの差の有無は不明**。
- 売り買いの差の検証をした個人の記事は、見つからなかった。

### 1-4. 預り区分

- 通常の注文画面には**一般預り・特定預り・NISA 預り**が出る。**S 株を NISA 預りで買えるか**（NISA 成長投資枠で単元未満株）は、検索では確認できなかった。**予行演習は『特定』を選ぶ**（stocks_live.md の前提）。

### 2-2. moomoo の補足

- 公式の概要: 開発者向けページは **HK・US・CN・SG・JP・MY の市場**を対象とし、取引の概要ページも**日本・カナダ・先物などの市場**を含むと書く。注文は「発注・変更・取消」「実口座は先にロック解除（unlock）が必要」。
- 一方、moomoo 証券（日本）の「Moomoo API」の案内は**米国株の自動売買を中心**に紹介し、**日本株の API 取引の記載は見つからなかった**。
- 確かめ方（推測）: moomoo 証券の口座を開き、OpenD に接続して、API の「許可された取引口座の取得」で**日本株の口座が出るか**を見る。ここまでは利用者の作業（口座開設）が先に要る。

### 2-3. 証券会社のサイト・アプリをプログラムで画面操作して注文する方法

- **SBI の規約で自動操作（スクレイピング・自動ログイン・自動発注）が禁止されているかは、本文に届かず確認できなかった**。見つかったのは、SBI 証券のスマートアプリの使用許諾（用途は認証と情報の確認に限定、細部は『約款・規程集』による）だけ。禁止事項は『約款・規程集』のインターネットサービス利用規約にある可能性が高い。
- 他社の自動売買の比較でも、SBI は逆指値などの標準の自動注文はあるが、画面操作の自動化を許す記載はない。外部の自動売買ツールの存在は、**SBI が許容している根拠にならない**。
- **結論（推測）**: 画面操作の自動化は、規約違反・口座の制限・誤操作のリスクがあるので**やらない**。自動化するなら、**公式の API がある業者**（立花、moomoo）を、規約と対象を確認した後で別に事前登録する。**当面は、『計算と一覧づくりと通知を自動、注文の送信は手』**が、規約上も安全な最大限の自動（stocks_live.md の 7 章と整合）。

## 3. Mac から iPhone に知らせる手段（毎日 13:05 の判断の後に、注文の一覧を送る）

## 4. 分析役・指令役への示唆

- **stocks_live.md の 4.1 の空欄**は、公式の抜粋を根拠に **「10:30〜14:00 の注文 → 当日の後場の引け（15:30）」**と書ける。ただし 14:00 と 13:30 の食い違いがあるので、**利用者に『S 株取引ルール』のリンク先を開いてもらい、表の画面を送ってもらって**から確定するのが安全。確定までは、**安全側で『13:30 までに出す』**にすると、どちらの版でも引けで約定する。
- **13 時台の運用は成り立つ**。13:05 の自動実行が終わってから、**13:30 まで**（安全側）に 5 銘柄の買いと売りを出す。20〜25 分の余裕しかないので、通知の遅れと、`orders` が 13:10 までに終わることが重要。
- 画面に『価格』『期間』の欄があるが、**成行・当日中のまま触らない**。**市場の選択は、リンク先を読むまで既定のままにする（変える場合は小さな金額で試す）**。
- 自動化は、**計算・一覧・通知を自動にし、注文の送信は手**（規約と対象が確認できる API が見つかるまで）。立花・moomoo の API は、利用者が約款を読む・口座を開く前提の別の事前登録にする。
- 見つからなかったこと: S 株のスプレッド、S 株の画面の市場選択の意味、S 株の約定方式の変更の告知、立花の単元未満株・規約・審査、moomoo の日本口座の API 実注文、SBI の自動操作の禁止条項、iMessage の自分宛ての通知。
